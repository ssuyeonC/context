먼저 짚을 점: 우리가 정한 (2)에서 부가정보가 **스팟 소유**가 되면 이 화면은 "옵션 1개 = 스팟 1개"에 가까워져서 스팟 ID가 자연스럽게 붙어. 다만 지금 스크린샷은 옵션 1개가 여러 스팟에 연결되는 현재(글로벌) 구조라, **1:N도 감당되는 UI**로 잡는 게 안전해. 그 전제로 제안할게.

## 추천: 테이블 → "옵션 카드 리스트" (컨트롤은 위, 스팟은 아래 메타)

각 옵션을 한 줄 테이블 대신 **2단 카드**로:

```
┌───────────────────────────────────────────────────────────────┐
│ ⣿  [ 온다 80kj+슈링크유니버스 400샷+리진뷔주사 ]  [저장][번역관리][삭제] │
│     연결된 스팟  #1024 강남OO의원  #2087 압구정OO  #331 …  외 2  │  ← 회색 태그, 줄바꿈
└───────────────────────────────────────────────────────────────┘
```

- **1행(조작)**: 드래그·라벨·저장·번역관리·삭제 — 지금 그대로 유지
- **2행(메타)**: `연결된 스팟`을 **태그(칩)**로. 각 칩은 `#ID 스팟명`, 클릭 시 해당 스팟으로 이동. 많으면 `외 N` 접기
- 연결 없으면 `연결된 스팟 없음`(회색)
- 번역관리 옆에 **번역 상태 뱃지**(완료/미완료) 같이 두면 검수 뷰로도 바로 쓸 수 있음

→ 테이블의 "칸 맞추기" 압박에서 벗어나고, 스팟이 1개든 N개든 자연스럽게 늘어나. 조작 요소와 정보 요소가 위아래로 분리돼 시선도 안 엉켜.
