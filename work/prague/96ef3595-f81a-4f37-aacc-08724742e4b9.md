## 오배정 = "주소의 시도 ≠ 좌표의 시도"
- 각 스팟의 **`legal_code`는 좌표를 법정동에 매핑한 결과**입니다 → `legal_code` 앞 2자리 = **좌표가 실제로 찍힌 시도**
- 스팟의 **`address`(텍스트)에서 시도**를 뽑아(서울/부산/강원/경기 …), 이 둘을 비교
- **다르면 플래그**. 예:
  - `12157`: 주소 "**강원** 고성군 간성읍…" 인데 좌표 legal_code = `11`(**서울**) → 좌표가 서울에 찍힘
  - `14611`: 주소 "**서울** 종로 사직로 161"(경복궁) 인데 좌표 = `41`(**경기**) → 좌표가 경기에 찍힘
- 즉 **"좌표가 틀렸다"는 정확히는 "주소와 좌표가 시도 레벨에서 안 맞는다"** 는 뜻이고, 12개가 서울로 몰린 정황상 좌표가 기본값/오타로 잘못 세팅된 걸로 추정한 것
