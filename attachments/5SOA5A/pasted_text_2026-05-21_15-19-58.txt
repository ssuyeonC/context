운영팀이 먼저 처리하고 알려주는 흐름인가요? | **운영팀 선처리 → 카톡 통보** 가설 검증 |  |

## 영역 4. 시즌 콘텐츠 변경 흐름 (10~15분, **핵심**)

> 투어스토리에서 가장 중요한 영역. 시즌(벚꽃/단풍/스키) 사이클이 곧 콘텐츠 사이클.
> 

### 4-A. 직전 시즌 사례 따라가기 (필수)

| 질문 | 의도 | 응답 |
| --- | --- | --- |
| 직전 봄/벚꽃 시즌(3~4월)에 진해 군항제·서울 겹벚꽃 같은 상품을 노출 시작/종료하셨잖아요. 그 작업을 어떻게 하셨어요? | **마지막 사례 확보 — 시즌 오픈** | 날짜 마감은 가능하기 때문에 상품 마감으로 인해 발생하는 문제는 없음 |
| 그 작업, 누가 결정했고 실제로 손이 들어간 분은 누구셨어요? 크리에이트립 매니저였나요 투어스토리 직원이었나요? | 권한 분담 |  |
| 가격, 일정, 출발 일자, 미운행 처리는 어디서 어떻게 입력됐어요? | **시즌 오픈 동선** |  |
| 시즌 오픈부터 실제 노출까지 며칠 걸렸어요? 늦어진다고 느끼신 적은? | 체감 처리 시간 |  |
| 그동안 유저 노출은 어떻게 됐어요? 잘못된 일정으로 예약 들어와서 문제 된 적은? | 비즈니스 임팩트 |  |
| 그 작업 동안 매니저와 따로 카톡/전화하신 게 몇 번이나 있었어요? | **우회 경로 빈도** |  |
| 데이터로 보면 어드민에서 시간슬롯·요일별 정책 수정은 600건 넘게 하시는데, **가격/코스/투어 설명/사진** 같은 콘텐츠 수정은 단 2건뿐이에요. 시즌마다 가격이나 코스가 바뀌실 텐데 그건 어떻게 처리하세요? | **일정은 셀프, 콘텐츠는 위임 가설 검증** |  |
| 어드민에 "스팟 정보 수정 요청" 메뉴가 있는 건 알고 계세요? 일정은 직접 하시면서 정보 수정은 안 하시는 이유가 있어요? | 영역별 채널 선택 |  |
| 사실 시간슬롯과 요일별 정책은 자동 승인이라 어드민에서 즉시 반영되는데, **가격이나 코스/일정표 같은 콘텐츠 수정은 어드민으로 요청하셔도 운영팀 검수**를 거쳐야 반영돼요. 이 절차가 번거로워서 카톡으로 부탁하시는 게 더 편하셨던 건가요? | **승인 채널 가시성 차이 — 어드민 요청 = 블랙박스 vs 카톡 = 사람 응답** |  |
| 가격이나 코스/일정표 수정을 카톡으로 부탁드리시면, 그 뒤 진행 상황은 어떻게 아세요? 매니저가 "받았어요 → 검토 중 → 반영됐어요" 같이 단계별로 알려주시나요, 아니면 57개 스팟 일일이 직접 확인하세요? | **카톡 = 사람 응답 가설 + 다스팟 검증 부담** |  |
- 파트너 어드민 내 검색 기능
    - 상품 ID
    - 상품 명
    - 직접 외국어를 선택해서 편집할 수 있는 기능 / 특정 언어로 편집하고 해당 언어 기반으로 AI 번역될 수 있도록 하는 것
- 마감은 직접 가능한데, 추가나 수정은 요청을 드려야 가능한 상황
- 다른 OTA는 최초 검수가 끝나면 그 뒤로는 자유롭게 진행함(제한적으로 진행함), 큰 OTA는 대부분 검수 절차가 없음. 가격, 썸네일 등 중요하고 민감한 부분들은 OTA 업체에서 한번 더 검수하는 절차는 있음

| 변경 요청을 보낸 뒤, 실제로 사이트에 반영되기까지 얼마나 걸린다고 느끼세요? | 체감 처리 시간 |  |

| 투어 상세 페이지(코스 설명, 일정표, 사진) 내용을 직접 수정하고 싶으셨던 적이 있으세요? 어떤 부분을요? | **콘텐츠 직접 수정 의향** |  |

| 만약 직접 예약을 어드민에서 확인하고 승인할 수 있다면, 도움이 될까요 부담일까요? | 의향 |  |
| 직접 예약을 처리하지 않는 가장 큰 이유가 무엇이라고 생각하세요? | 핵심 미사용 이유 |  |

| 다른 OTA(클룩, KKday, 트립닷컴, 마이리얼트립)도 같이 쓰세요? 어드민 사용 빈도 비교하시면 어떠세요? | **OTA 어드민 비교** | 100% 컨트롤할 수 있도록 되어 있음. KKday는 반 정도는 투어스토리에서 컨트롤. 대부분 처음으로 AI 자동번역, 필요한 수기로 수동 번역. |
| 투어스토리는 카카오 알림톡 채널이 OFF 상태라 알림톡으로 예약 알림을 받지 않으세요. 그게 의도하신 건가요, 모르고 계셨던 건가요? 만약 켜진다면 57개 스팟 알림이 한꺼번에 와도 괜찮으세요? | **알림톡 미수신 인지 + 다스팟 알림 폭주 우려** |  |
