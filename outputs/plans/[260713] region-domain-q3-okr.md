# 지역 도메인 개선 — 3분기(Q3) 목표(OKR)

> 🔗 **허브**: `outputs/plans/[260701] region-domain-improvement-master.md` — 지역 도메인 개선 통합 기획서 (전체 문서 맵)

작성일: 2026-07-13
상태: **초안 (잠정 베이스라인)** — 헤드라인·프레이밍·측정정의 확정. 수치는 리서치 문서 실측치를 잠정 적용, **라이브 실측은 GA/GSC 접근 복구 후 보정**(§4).
스코프: 지역 도메인 개선은 Q3의 여러 목표 중 하나. 본 문서는 그중 **지역 도메인 트랙**에 한정.

> **한 줄 요약** — 이 목표의 스코프는 "프로젝트 완수"가 아니라 **"지역 도메인이 크리에이트립에 만드는 기여"**다. 기여는 전사 지표(전체 유입·전환)가 아니라 **지역 도메인이 직접 통제·귀속 가능한 지표**로 잰다: 여행자 관심사 기반 SEO 지역 페이지가 만드는 **오가닉 유입 × 스팟 전환**.

---

## 1. Objective

**여행자 관심사 기반 SEO 지역 페이지로 오가닉 유입과 스팟 전환에 기여한다.**

- **왜 전사 지표가 아닌가** — 지역 도메인 개선이 전체 유입/전환에 미치는 기여도는 귀속이 어렵고 외부변수(시즌·마케팅·환율 등)가 너무 많다. 그래서 **지역 페이지 표면에서 측정되는, 지역 도메인이 만들어낸 순증분**만 목표로 둔다.
- **왜 이 두 레버인가** — 애초 지역 도메인을 개선하려던 의도가 ① 리서치로 알아낸 여행자 관심사(테마·구역)를 반영한 페이지를 **SEO 친화적으로** 만들어 **오가닉 유입**을 늘리는 것, ② 그 페이지 안에서 **스팟 전환**을 높이는 것이었다.

## 2. 헤드라인 지표 (복합 단일)

```
지역 페이지發 오가닉 → 스팟 전환 세션 수
   = 오가닉 유입 세션 (레버1)  ×  페이지 → 스팟 전환율 (레버2)
```

- **하나로 묶는 이유**: 두 레버의 곱이라 어느 쪽이 깨져도("유입은 왔는데 스팟 안 넘어감" / "전환은 좋은데 유입이 없음") 이 숫자가 잡아낸다. 전사 지표처럼 외부변수에 오염되지 않고, 지역 페이지가 만들어낸 순증분만 센다.
- **상승 작용**: 오가닉 검색자는 의도("seoul restaurants")를 갖고 테마 매칭 페이지에 착지 → 내부 브라우징 유저보다 전환율이 구조적으로 높다. 레버1을 키우면 레버2도 함께 오르는 방향.
- **두 레버 운영(실측 반영)**: **① 유입** = 오가닉 진입 세션(방문페이지 기준) · **② 전환** = 페이지→스팟 클릭률(`spotProductCardClick`/`page_view`, page_view 기준). 예약(주요이벤트)은 절대값 작아(월 6~19건) 후행 참고로 강등.
### 실측 베이스라인 (2026-06-12~07-12, 최근 1개월 · GA)

**기준 = 방문 페이지(진입, landing page) `/spot/region/` 포함** — SEO 유입(검색으로 지역 페이지에 착지)의 정의에 맞는 기준. '페이지 경로 포함' 기준은 내부 이동으로 지역 페이지에 도달한 세션까지 세어 유입을 과대계상하므로 채택 안 함(§4 주).

| 채널 | 진입 세션/월 | 조회수/월 | 참여시간 | 주요이벤트 | 전환율 |
|---|---|---|---|---|---|
| 전체 | 1,946 | 10,370 | 13초 | 19 | 0.62% |
| **Organic Search** | **652 (33.5%)** | **4,758 (46%)** | **30초** | 6 | **0.94%** |
| Direct | 1,269 | 5,365 | 4초 | 12 | 0.39% |

- **⚠️ '오가닉 ≈ 0' 가정 폐기** — 방치된 자동생성 페이지(`/spot/region/{id}` 498개)인데도 **오가닉이 지역 페이지 진입의 33.5% = 2위 채널**. 오가닉 체류 **30초로 Direct(4초)의 7배** → 강한 의도 유입. 논지가 이미 데이터로 뒷받침됨.
- **→ 목표는 '0→만들기'가 아니라 '기존 오가닉 진입을 페이지 개선으로 키우기'.**
- **Q3 목표 — 두 레버: ① 오가닉 진입 652 → ~1,000/월 (+~50%) · ② 페이지→스팟 클릭률 0.93% → 2.0%** (리스트 2.96% 벤치). (서울 비치헤드, 근거 §3.5)

## 3. Key Results

> 성격: Q3는 **토대 구축 + 서울 비치헤드 첫 측정**. SEO 오가닉은 색인·랭킹에 분기+가 걸려, Q3는 선행지표 중심 + 오가닉 세션 베이스라인/소폭 목표까지. 본격 성숙·상향은 Q4(§6).

### KR1 — SEO 친화 지역 페이지 라이브 (서울 비치헤드) · *Enabler*
- 지역 데이터 legal 정합 완료: CITY 시도 승격 + DL 시군구 legal 전량 시딩 + 스팟 CITY/DL 일괄 재태깅(97.5% 자동 / 미코드 159·오배정 20 보정).
- 서울 REGION/CITY + **테마 leaf 페이지** 배포: **서울 구역(REGION) 10개** × 테마 → **색인 테마 leaf 30개**.
- SEO 가드레일: 4단 slug · `/spot/region/{id}` → 301 · canonical 정본 · 콘텐츠 임계 10(미만 leaf 비색인).
- **완료 기준**: 표기 일관성 검수 통과 · dangling 0 · 서울 페이지 유저 노출.

### KR2 — 오가닉 유입 (레버1) · *실측 성장*
- **오가닉 진입 세션: 652 → ~1,000/월 (+~50%)** · 오가닉 조회수: 4,758 → ~7,000/월. (방문페이지 기준 · 서울 구역·테마 leaf 질 개선 + 색인 확대 · 벤치: 상세 페이지당 오가닉 효율의 ~8배 헤드룸)
- **선행지표**: 색인 테마 leaf **30개**(신규 색인 표면), GSC 타깃 키워드셋 노출·평균순위 측정 개시(GSC 권한 확보 시).
- 타깃 키워드셋: 도시×테마('seoul restaurants' 등) — 전체 기회 월 ~50만 추정(master §1).

### KR3 — 페이지→스팟 클릭률 (레버2) · *아웃컴*
- **전환 지표 = 페이지→스팟 클릭률** (`spotProductCardClick` 사용자 / `page_view` 사용자, **page_view 기준**). ✅ 정의 확정.
- **지역 현재 0.93%** (클릭 18 / 뷰 1,936) vs **리스트 벤치 2.96%** (2,018 / 68,107) → 지역이 **3.2배 낮음** = 큰 전환 헤드룸.
- **Q3 목표: 0.93% → 2.0%** (리스트 2.96%가 스팟 브라우즈 페이지의 정상치 → 큐레이션 지역 페이지도 도달 가능, Q3는 3배 근접). 예약(0.94%)은 후행 참고로 강등.
- **리스트→지역 유입 위젯 출시**: 스팟 리스트(체류 49초)에 '지역으로 둘러보기' 위젯 → `/region`. 내부 트래픽으로 전환 측정·최적화 채널. (서울 페이지 라이브 후 소프트오픈)

### 3.5 헤드라인 산출 (실측 기반)

최근 1개월(6/12–7/12) 실측 → Q3 목표.

| 레버 | 현재(월) | Q3 목표(월) | 벤치마크 |
|---|---|---|---|
| ① 오가닉 진입 (유입) | 652 | ~1,000 (+~50%) | 상세 페이지당 효율의 ~8배 헤드룸 |
| ② 페이지→스팟 클릭률 (전환) | 0.93% | 2.0% | 리스트 2.96% |
| = 지역發 스팟 클릭 (전체·참고) | ~18 | ~40 | 뷰↑ × CTR↑ |

> '오가닉 ≈ 0'을 폐기하고 **실측 위에서** 두 레버로 재설정: **유입** 오가닉 진입 652→~1,000/월(+~50%, 상세 대비 페이지당 8배 헤드룸), **전환** 페이지→스팟 클릭률 0.93%→2.0%(리스트 2.96% 벤치, 지역이 현재 1/3). dau-model 경고(단순 방문↑ ≠ 임팩트)에 대응해 **유입·전환을 함께** 건다. 목표치는 SEO 색인 지연 고려 Q3말 run-rate 기준의 잠정치, 진행 중 재보정.

## 4. 측정 정의 & 데이터 원천

| 지표 | 정의 | 원천 | 현재 값 (6/12–7/12, 월) |
|---|---|---|---|
| **오가닉 진입(세션)** | **방문페이지** `/spot/region/` 오가닉 세션 · **주지표** | GA (`sessionDefaultChannelGroup=Organic Search`) | **652** |
| 오가닉 조회수 | 위 진입 세션 조회수 | GA | **4,758** |
| 전환율(주요이벤트) | 진입 세션 중 주요이벤트(예약 등) · 가드레일 | GA | **오가닉 0.94%** / 전체 0.62% |
| **페이지→스팟 클릭률** (전환 KR) | `spotProductCardClick` 사용자 / `page_view` 사용자 (page_view 기준) | GA 이벤트 | **지역 0.93%** (18/1,936) / 리스트 벤치 2.96% (2,018/68,107) |
| (참고) 오가닉 체류 | 오가닉 평균 참여시간 | GA | 30초 (Direct 4초) |

> ⚠️ **기준·출처** — **방문페이지(진입) 기준** 채택: SEO 유입 = "검색으로 지역 페이지에 착지"라 진입 기준이 정의에 부합. '페이지 경로 포함' 기준(오가닉 1,506)은 딴 페이지로 착지 후 내부 이동으로 지역 페이지에 도달한 세션까지 세어 지역 페이지의 유입 기여를 **과대계상** → 미채택(도달·reach 보조지표로만 참고 가능). 실측은 GA 수동 리포트(2026-06-12~07-12)로 확보. 프로그램적 접근은 제한: GA4 MCP OAuth 만료, Search Console BQ 권한 없음, GA4 events export 미발견. **KR2 GSC 선행지표·페이지→스팟 클릭률은 접근 복구 후 측정 추가.**

## 5. 순서 · 의존성

```
KR1 (데이터 정합 → 서울 페이지 라이브)
   → KR3 위젯 소프트오픈 (내부 트래픽으로 전환 먼저 튜닝)
   → KR2 SEO 색인·오가닉 성숙 (leading → lagging)
```
- 유입 위젯은 서울 페이지 라이브(KR1) 이후에만 개방 — master 원칙 "깨진 페이지에 트래픽 먼저 붓지 않음".
- 오가닉(KR2 lagging)은 색인 지연으로 Q3말 물꼬 트임, 본격 성숙은 Q4.

## 6. Q3 밖 (분기 크기 관리 · Q4↑)

- **전국 확장** (서울 외 도시 REGION/페이지) — Q4.
- **관광지·동 DL 최종 삭제(REGION cutover)** — 후속 트랙.
- **스팟 상세·검색 region 표기·검색** (`[260715] region-creation-and-cutover` — 구 `[260708]`에서 통합) — 병렬로 계속하되 본 목표의 KR은 아님.
- **CITY 테마축 = home-nav 전역 1개 확정**(master §5-2) — 모든 `/region/{city}` 공유. 남은 후속만: master_theme 통일 여부 · 도시별 커스텀 정렬(상세 `[260831]` 열린결정 #3).
- 오가닉 세션 lagging 본격 상향 · 오가닉 트래픽 기준 전환 재측정 — Q4.

## 부록: 확정 이력

- **스코프** — 프로젝트 완수 아님, **지역 도메인의 기여**(전사 지표 아님, 지역 페이지 표면 귀속 지표).
- **두 레버(KR)** — ① 오가닉 진입(유입, 방문페이지) 652 → ~1,000/월(+~50%) · ② 페이지→스팟 클릭률(전환, page_view) 0.93% → 2.0%.
- **벤치마크** — 전환: 리스트 2.96% vs 지역 0.93%(3.2배 낮음) · 유입: 상세 페이지당 오가닉 효율의 ~8배 헤드룸.
- **실측 베이스라인 (2026-06-12~07-12)** — 오가닉 진입 652세션·조회수 4,758·체류 30초 / 페이지→스팟 클릭 0.93%(18/1,936).
- **Q3 오가닉** — 선행 + lagging(오가닉 세션 베이스라인/소폭 목표까지).
- **비치헤드** — 서울.
- **KR-C 유저 표면** — 리스트→지역 유입 위젯(전환 검증 채널).
