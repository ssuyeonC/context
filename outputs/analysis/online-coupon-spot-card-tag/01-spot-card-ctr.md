# 01. 스팟 카드 CTR — 태그 노출 전/후 (핵심)

## 목적

'온라인 쿠폰' 태그가 스팟 카드의 **클릭(상세 진입)을 끌어올렸는지**를 본다. 태그가 닿는 대상(쿠폰 보유 스팟)의 CTR이 태그 도입 후 올랐는지, 그리고 그 상승이 자연 추세가 아니라 태그 효과인지를 분리한다.

## 핵심 질문

1. 쿠폰 보유(태그 노출) 스팟의 카드 CTR이 태그 도입 **전 대비 후**에 올랐는가?
2. 같은 기간, 쿠폰 미보유(태그 없음) 스팟 대비 **상대적으로 더** 올랐는가? (자연 추세 제거)

## 지표 정의

- **CTR(프록시)** = `SpotProductCardClick 수` / `해당 면 페이지뷰(또는 세션)` — README의 분모 주의 참고
- 정밀화 시: `클릭수 / 카드 노출수`(노출 이벤트 추가 후)
- 면(surface) 한정: `location`이 리스트/검색에 해당하는 클릭만 집계 (상세·홈 추천 등 제외)

## 세그먼트

- **처치군(treatment)**: 태그 노출 조건을 만족하는 스팟 (활성+노출 쿠폰 연결, 뷰티 캐시백 OFF) — 현재 8개
- **대조군(control)**: 쿠폰 미연결(또는 미노출) + 뷰티 캐시백 OFF 스팟
- (분리) 뷰티 캐시백 스팟은 태그 우선순위상 온라인 쿠폰 태그가 안 뜨므로 두 군에서 제외하거나 별도 군으로 둔다.

## 방법

- **기본: Diff-in-Diff (이중차분)**
  - 축1: 시간 — 태그 출시일 전 N주 vs 후 N주
  - 축2: 군 — 처치군(쿠폰 보유) vs 대조군(미보유)
  - 처치군의 전후 변화에서 대조군의 전후 변화를 빼, **태그에 귀속되는 증분**을 추정
- 보조: 처치군에 대한 **단절적 시계열(interrupted time series)** — 출시 시점 전후 CTR 추세 단절 확인
- 표본 주의: 처치군이 8개 스팟으로 작다 → 스팟별 트래픽 편차 큼. 스팟 단위가 아니라 **클릭/페이지뷰 합산** 기준으로 보고, 신뢰구간을 함께 본다. (소표본이라 통계적 유의성보다 방향성·효과크기 위주로 해석)

## 데이터 소스

- GA4 `SpotProductCardClick` (파라미터 `code`, `location`, `keyword`)
- 처치군 스팟 코드 목록 = 아래 DB 쿼리로 확보 (분석 시점마다 갱신)
- 분모(페이지뷰): 리스트/검색 면의 `page_view` 또는 세션 수

### 처치군 스팟 코드 추출 (DB)

```sql
SELECT DISTINCT s.code
FROM spot s
INNER JOIN online_coupon_has_linked_domain d
  ON d.linked_domain_id = s.code AND d.linked_domain_type = 'SPOT'
INNER JOIN online_coupon c
  ON c.id = d.online_coupon_id AND c.is_active = 1 AND c.is_exposed = 1
WHERE s.is_beauty_cash_back = 0;
```

### 클릭 집계 (GA, 의사코드)

```
SpotProductCardClick
  where location in (리스트/검색 면)
  group by (기간: pre/post), (군: code ∈ 처치군 ? treatment : control)
  metric: event_count, (분모) 해당 면 page_view
```

## 산출물

- 처치군/대조군 × pre/post 2×2 표 (클릭수, 프록시 CTR)
- DiD 증분 추정치 + 방향성 코멘트
- 베이스라인 값: 처치군의 **pre 기간 프록시 CTR** (제안서/요구사항의 'TBD'를 채울 값)

## 주의·한계

- 표본 작음(8 스팟) → 결과는 **참고 수준**. 노출 대상이 늘면(관공서 수주 확대) 재측정.
- 분모 프록시의 한계(README) — 절대 CTR이 아니라 **상대·전후 비교**로만 해석.
- 태그 외 동시 변경(가격·정렬·프로모션)이 있으면 DiD 가정이 깨질 수 있음 → 출시 전후 변경 이력 확인.

### 한계 (이번 측정 한정)

- 상세 PV는 모든 유입경로 합산이라 **리스트 카드 클릭만의 기여를 분리하지 못함**.
- 캠페인 출시(5월)와 태그 출시 시점이 겹치면 효과 귀속이 어려움 → 태그 출시일을 캠페인과 어긋나게 잡거나, 노출 이벤트 도입 후 측정 권장.
