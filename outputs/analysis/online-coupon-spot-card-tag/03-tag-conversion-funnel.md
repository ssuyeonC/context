# 03. 태그 → 상세 진입 → 쿠폰 적용 결제 퍼널 + 카니발리제이션

## 목적

태그의 가치가 **클릭(CTR)에서 끝나는지, 실제 예약·쿠폰 사용까지 이어지는지**를 본다. 또한 "태그가 없었어도 어차피 들어와 결제했을 유저"(카니발리제이션)를 가시화해, 순증분을 분리한다.

## 핵심 질문

1. 쿠폰 보유 스팟 카드 클릭 유저의 **상세 진입 → 예약/결제 → 쿠폰 적용** 전환이 어떻게 되는가?
2. 태그 도입 후, 이 스팟들의 **쿠폰 적용 결제 건수·금액**이 늘었는가?
3. 그 증가분 중, 태그가 없었어도 발생했을 자연 전환(카니발리제이션)은 얼마인가?

## 퍼널 정의

```
리스트/검색 노출(또는 페이지뷰)
  → SpotProductCardClick (쿠폰 보유 스팟)
    → 스팟 상세 조회
      → 예약/결제 시작
        → 결제 완료
          → 그 중 온라인 쿠폰 적용 결제
```

## 지표

- 단계별 전환율 (특히 클릭→결제완료, 결제완료 중 쿠폰 적용 비율)
- 쿠폰 적용 결제 **건수·거래액·할인액** (전/후)
- 카니발리제이션 지표: 태그 도입 전부터 이미 발생하던 해당 스팟의 쿠폰 적용 결제 베이스라인

## 방법

- GA `SpotProductCardClick`(쿠폰 보유 스팟) → 결제 이벤트/주문 데이터 조인 (BigQuery, user/session 키)
- 쿠폰 적용 결제는 결제(payment) 측 주문-쿠폰 사용 기록으로 확인 (`online_coupon.usage_count`, 사용 이력 테이블)
- **카니발리제이션**: 태그 도입 **전** 기간, 동일 스팟들의 쿠폰 적용 결제량을 베이스라인으로 두고, 도입 후 증가분에서 베이스라인 추세분을 차감
  - 기획 프레임 Q3 관점: "이 태그가 없었다면 이 타깃은 어떻게 행동했을까?" — 쿠폰 보유 스팟은 상세에서 이미 쿠폰이 보이므로, 자연 전환이 일정 부분 존재한다고 가정하고 그 위의 증분만 효과로 본다.

## 산출물

- 퍼널 단계별 전환표 (전/후)
- 쿠폰 적용 결제 전/후 비교 (건수·금액·할인액)
- "자연 수준 + 증분" 분해 한 줄 정리

## 주의

- 표본 작음(8 스팟) + 결제는 더 희소 → 건수 부족하면 **금액/건수 절대치와 방향성** 위주로, 유의성 단정 금지.
- 쿠폰 사용은 결제 외 채널(현장 등) 변수 있음 → '온라인 쿠폰 적용 결제'로 한정.

## 측정 결과 (2026-06-01 기준) — 부분

> 소스: `dashboard_ga4.SpotDetailPV`(상세 PV, 예약정보 진입). **결제·쿠폰 적용 단계는 미집계**(태그 미출시 + 캠페인 발급 직후라 표본 거의 없음). 아래는 상위 퍼널(상세 → 예약정보 진입)까지만.

### 상세 PV → 예약정보 진입 (8개 합산)

| 기간 | 상세 PV | 예약정보 진입 | 진입율 |
|---|---|---|---|
| 2026-01 ~ 05 누적 | 1,438 | 43 | **3.0%** |
| 2026-05 (캠페인 개시월) | 698 | 30 | **4.3%** |

- 캠페인 개시월(5월)에 상세 PV·예약정보 진입이 함께 급증(진입율도 3.0%→4.3%). 단 이는 **쿠폰 발급 + 외부 마케팅** 효과이며 **리스트 태그와 무관**(태그 미출시).

### 스팟별 예약정보 진입 (2026-03~05)

- 14485 클럽디오아시스 13건, 15208 크레이지서퍼스 16건이 진입의 대부분. 나머지 스팟은 0~3건.
- 즉 **도달은 상위 4개, 예약 의향은 14485·15208에 집중**. 결제 전환 측정 시 이 두 스팟이 신호의 중심이 될 가능성.

### 남은 작업 (태그 출시 후)

- 결제 완료·온라인 쿠폰 적용 결제는 결제 데이터(`issued_online_coupon`, `payment_transaction`, `online_coupon.usage_count`)와 조인해 별도 집계.
- 카니발리제이션: 캠페인 발급 전 베이스라인 결제가 사실상 없으므로(신규 캠페인), 이 캠페인은 **증분=거의 전량**에 가깝다고 보되, 향후 상시 캠페인에서는 발급 전/후 분리 필요.
