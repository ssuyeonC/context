# 04. 뷰티 캐시백 태그 벤치마크 (기대 증분 추정)

## 목적

'온라인 쿠폰' 태그는 **뷰티 캐시백 태그와 같은 자리·같은 패턴**으로 동작한다. 따라서 먼저 출시된 뷰티 캐시백 태그가 카드 클릭에 준 영향을 측정해, 온라인 쿠폰 태그의 **기대 증분을 사전 추정**하는 참고선으로 쓴다. (출시 전, 측정 없이 기대치를 잡고 싶을 때 유용)

## 핵심 질문

1. 뷰티 캐시백 태그가 붙은 스팟(90개)의 카드 CTR은 미부착 유사 스팟 대비 높은가?
2. 뷰티 캐시백 태그 도입 시점 전후로 해당 스팟 CTR이 올랐는가?
3. 거기서 얻은 상대 리프트를, 온라인 쿠폰 태그 기대치로 옮길 때의 보정 요인은?

## 방법

- 01과 동일한 CTR(프록시) 정의·DiD 틀을 **뷰티 캐시백 태그**에 적용
  - 처치군: 뷰티 캐시백 ON 스팟(90개) / 대조군: 유사 카테고리의 태그 미부착 스팟
  - 뷰티 캐시백 태그 도입 시점(마이그레이션 `is_beauty_cash_back` 추가 ≈ 2025-12) 전후 비교
- 산출된 상대 리프트(%)를 온라인 쿠폰 태그의 기대 리프트로 차용, 단 아래 보정.

## 보정 요인 (벤치마크를 그대로 못 쓰는 이유)

- **혜택 성격 차이**: 캐시백(적립) vs 쿠폰(즉시 할인) — 유저 인지·매력도가 다를 수 있음
- **카피·아이콘 차이**: 태그 문구/색이 다르면 주목도 차이
- **모수 차이**: 뷰티 캐시백 90개 vs 온라인 쿠폰 8개 — 트래픽 분포 다름
- 따라서 벤치마크는 **상한·하한 범위 추정**으로 쓰고, 단일 점추정으로 단정하지 않음

## 산출물

- 뷰티 캐시백 태그의 CTR 리프트(%) 추정 (DiD)
- 보정 후 온라인 쿠폰 태그 기대 리프트 **범위**
- "벤치마크 기준 기대치 vs 실제(01 결과)" 사후 대조표 (출시 후)

## 주의

- 이건 **참고 추정**이지 측정 대체가 아니다. 출시 후 01의 실제 결과로 교체.

---

## 측정 결과 (2026-06-01 기준) — 보류

- 이 벤치마크의 핵심(뷰티 캐시백 태그의 **CTR 리프트**)은 01과 **같은 데이터 공백**에 막혀 있다: 카드 단위 노출/클릭이 트래킹되지 않아 태그별 CTR 리프트를 직접 산출할 수 없다.
- 따라서 이번 패스에서는 수치 미산출. 우선순위가 낮고(참고용), **카드 노출 이벤트가 생긴 뒤** 01과 동일한 정의로 함께 측정하는 것이 맞다.
- 대안(상한 추정이 급할 때): 뷰티 캐시백 90개 스팟의 `SpotDetailPV`를 태그 도입(≈2025-12) 전/후로 비교해 **상세 PV 추이 변화**를 리프트 프록시로 쓸 수 있으나, 이 역시 외부 트래픽이 섞여 정밀도가 낮다. 필요 시 별도 요청.
