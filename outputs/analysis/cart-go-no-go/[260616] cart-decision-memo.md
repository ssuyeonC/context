# 장바구니 도입 검토 — 의사결정 메모 (통합본)

작성일: 2026-06-16
관련: TRAVEL-3226 / 장바구니(Cart) 도입 검토
데이터 기준: BigQuery `dashboard_db.spot_sales`, 2025년, 회원·여행 도메인·패키지 제외

> 결론 먼저: **장바구니는 "있으면 편한" 기능이지 "없으면 안 되는" 기능이 아니다.** 확실한 가치는 작고 큰 가치는 미검증 → **성장 베팅을 할 의지가 없다면 데이터는 No-go.**

---

## 1. 핵심 프레이밍
**"장바구니 = 통합 결제(1 PG = N 예약)."**
통합 결제를 빼면 남는 건(모아두기·돌아오기·개별결제) 이미 있는 **좋아요(찜)와 동일**. 따라서 *"만들까"는 곧 "통합 결제를 만들까"* 이고, 3개월+영구 복잡도는 전부 여기서 나온다.

## 2. 측정 요약 *(2025 · 회원 · 여행 · 패키지 제외 / 모수 94,222예약 · GMV 152억)*
| 항목 | 값 | 의미 |
|---|---|---|
| 같은-세션 다건 결제 | **16억 (10.6%)** | 통합 결제가 직접 잡는 영역 |
| 14일 교차구매 | 44억 (29%) | 단, **64%가 교차세션(다른 날)** → 통합결제 무관, 좋아요로 이미 커버 |
| 단독 구매 | 71% | 한 여행=한 건이 대다수 |
| 다건 GMV 중 뷰티/의료/헤어 | 49% | **가치 최대 = 비용 최대**(헤어 보증금 89%, 메디컬 환불 39%) |

## 3. 비용 vs 효과 — 비대칭
| | 내용 | 크기 | 확실성 |
|---|---|---|---|
| **비용** | 개발 3개월 + 영구 복잡도(부분환불 상시·포인트배분·3DS·보증금정산) | 큼 | 🟢 확실 |
| **확실한 효과** | 마찰 제거(16억·세션 6.2%) + 인프라 자산 + 이탈 방어 | 작음(증분 마진 <2천만/년) | 🟢 확실 |
| **큰 효과** | attach 상승(29→35%면 ~1.2억 마진/년) + 번들 머천다이징 | 큼 | 🔴 미검증 |

→ **확실한 효과로는 확실한 비용을 못 덮는다. 큰 효과(🔴)가 실현될 때만 수지가 맞는 베팅.**

## 4. "만든다" 기대 효과 *(🟢측정 / 🟡기대 / 🔴미검증)*
- 🟢 **반복 결제 마찰 제거** — 연 6,462건 합침, 세션 6.2% UX 개선 (확실하나 작음)
- 🟡 **객단가 상승 / 인프라 자산**(다중예약 checkout → 향후 부가상품·동적번들 토대) / **경쟁사 패리티·이탈 방어**
- 🔴 **attach·교차구매율 상승** — 단독 구매자(71%) 일부 전환 시 의미 있는 증분, 단 미검증
- 🔴 **번들/큐레이션 머천다이징** — "세트 한 번에 결제" 인프라, 최대 잠재 upside지만 가장 불확실

## 5. "안 만든다" 근거
1. 장바구니의 실체(통합 결제)가 잡는 pie가 **작고(16억)** 이미 전환되는 거래 → 증분 마진 <2천만/년
2. 큰 교차구매(44억)는 **64%가 교차세션**이라 통합 결제로 못 잡고, **좋아요로 이미 커버**
3. 교차구매는 장바구니 없이도 **GMV 29%로 발생** = 플랫폼 안 막혀 있음
4. **가치 몰린 카테고리(뷰티/의료) = 비용 최대** → 잡으려면 복잡도를 떠안아야 함
5. 비용은 크고 **영구적**(부분환불이 엣지 아닌 일상)

## 6. 종합 판정 — 갈림길은 질문 하나
데이터가 답할 수 있는 한계까지 오면, 마지막은 전략 의지의 문제다:

> ### ❓ "크리에이트립이 attach 성장 + 번들 머천다이징을 성장 레버로 *실제로 투자*할 것인가?"

- **아니다 / 모르겠다 → 만들지 않는다.** (또는 풀빌드 전, 좋아요 기반 경량 실험으로 attach-lift를 먼저 실측)
- **그렇다 → 만든다.** 단 장바구니를 그 전략의 *인프라*로 포지셔닝하고, 담을 카테고리는 비용 보고 신중히 스코핑.

---
*기준: BigQuery `spot_sales`, 2025년, 회원·여행 도메인·패키지 제외. 교차구매=동일 회원의 가장 가까운 동반 결제가 14일 이내(7일 기준 시 25%). 모수=전 카테고리(카트 적격 한정 아님). GMV는 거래 시점 기준(환불 미차감).*
