# 장바구니를 "만든다" — 기대 효과 정리

작성일: 2026-06-16
관련: TRAVEL-3226 / 장바구니(Cart) 도입 검토
신뢰도 표기: 🟢 측정됨 / 🟡 기대·일부검증가능 / 🔴 베팅·미검증

## 1. 반복 결제 마찰 제거 🟢
같은 세션 다건 결제(연 6,462건, GMV 16억/10.6%)를 1건으로 합침. 결제 세션의 6.2%가 폼·카드 입력 반복에서 해방. **확실하지만 범위가 좁고**, 이미 전환되는 거래라 증분 마진은 작음(<2천만/년).

## 2. 객단가(결제당 금액) 상승 🟡
한 번에 여러 개 결제 → 결제 건당 금액 상승. 단 상당 부분은 "이미 살 것을 합치는" 효과라, 순수 신규분과 구분 필요.

## 3. 교차구매율 / attach 상승 🔴 (재무적으로 가장 중요한 기대)
결제 마찰이 줄면 2·3번째 상품을 덜 포기하고, 단독 구매자(GMV의 71%)의 일부가 다건으로 전환될 수 있음.
- *규모감:* 교차구매 비중이 29%→35%로 오르면 증분 GMV **~9억/년, 마진 ~1.2억/년**. 마찰제거 케이스(<2천만)보다 훨씬 의미 있음.
- *단, 이 lift는 과거 데이터로 검증 불가 — 핵심 가정.*

## 4. 결제·예약 인프라 현대화 🟡 (구조적 자산)
단건 중심 → 다중 예약 checkout 구조로 확장. 향후 **부가상품 판매·동적 번들·cross-sell**의 토대. PACKAGE 상품을 따로 안 만들어도 동적 묶음 결제 가능 → 운영 유연성.

## 5. 번들/큐레이션 머천다이징 인프라 🔴 (최대 잠재 upside)
큐레이션·기획전·여행 일정 페이지에서 "여러 상품 → 한 번에 결제"를 가능케 함. 콘텐츠를 구매로 잇는 전환 장치. **새 수요 창출 가능성**이 있으나 가장 불확실.

## 6. UX 기대치 충족 / 이탈 방어 🟡 (위생요인)
클룩·KK데이 수준의 표준 경험. 다건 구매하려던 유저의 "여긴 한 번에 결제가 안 되네" 이탈을 막음. **매력요인은 아니고, 없을 때의 마이너스를 막는 성격.**

## 구조 요약
| | 확실한 효과(🟢🟡) | 큰 효과(🔴) |
|---|---|---|
| 내용 | 마찰 제거, 객단가, 인프라 자산, 이탈 방어 | attach 상승, 번들 머천다이징 |
| 크기 | 작음 | 큼 |
| 확실성 | 높음 | 미검증 |

→ **확실한 효과는 작고, 큰 효과는 미검증.** "만든다"는 결정은 결국 **3·5번(attach 상승 + 번들 머천다이징)이 실현된다는 베팅에 3개월+영구 복잡도를 거는 것**이다. 1·2·4·6은 베팅이 빗나가도 남는 안전마진이지만, 그것만으로 3개월을 정당화하긴 약하다.
