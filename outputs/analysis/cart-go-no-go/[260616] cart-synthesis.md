# 장바구니 도입 — 종합 판정

작성일: 2026-06-16
관련: TRAVEL-3226 / 장바구니(Cart) 도입 검토

## 결정의 실체
"장바구니를 만들까?"는 곧 **"통합 결제를 만들까?"** 이다. 통합 결제를 빼면 남는 건 이미 있는 좋아요(찜)이므로, 모든 효과·비용은 통합 결제 하나에 걸려 있다.

## 비용 vs 효과의 비대칭
| | 내용 | 크기 | 확실성 |
|---|---|---|---|
| **비용** | 개발 3개월 + 영구 복잡도(부분환불 상시·포인트배분·3DS·보증금정산) | 큼 | 🟢 확실 |
| **확실한 효과** | 마찰 제거(16억 surface, 6.2% 세션) + 인프라 자산 + 이탈 방어 | **작음** (마찰 증분 <2천만/년) | 🟢 확실 |
| **큰 효과** | attach 상승(29→35%면 ~1.2억 마진/년) + 번들 머천다이징 | 큼 | 🔴 미검증 |

**핵심 비대칭:** 확실한 효과는 확실한 비용을 못 덮는다. **장바구니는 큰 효과(🔴)가 실현될 때만 수지가 맞는, 본질적으로 베팅이다.**

## 데이터가 말해주는 것 / 못 해주는 것
- **말해주는 것:** 교차구매는 이미 GMV의 29%로 잘 일어나고 있고(플랫폼 안 막힘), 통합 결제가 직접 잡는 같은-세션 pie는 16억으로 작으며, 그조차 이미 전환되는 거래다. → 마찰 제거 명분만으로는 3개월이 정당화 안 됨.
- **못 해주는 것:** "장바구니가 attach를 키울까", "번들 머천다이징이 수요를 만들까"는 과거 데이터로 검증 불가. 전략 의지의 문제.

## 최종 판정
> **데이터 단독 판정은 "조건부 No-go".**
> 마찰 제거·편의성·경쟁사 패리티만으로는 근거가 약하다. 장바구니가 정당화되는 **유일한 경로는 attach 성장 + 번들 머천다이징이라는 성장 베팅**이고, 그건 데이터가 아니라 **"우리가 그 전략을 실제로 밀 것인가"** 라는 의사결정에 달렸다.

## 갈림길은 하나의 질문
**"크리에이트립이 attach/번들 머천다이징을 성장 레버로 진짜 투자할 것인가?"**
- **아니다 / 모르겠다** → **만들지 않는다.** (또는 3개월 풀빌드 전, 좋아요 기반 경량 실험으로 attach-lift 가설을 먼저 실측)
- **그렇다** → **만든다.** 단 장바구니는 그 전략의 *인프라*로 포지셔닝하고, 담을 카테고리는 비용(뷰티 보증금·의료 환불)을 보고 신중히 스코핑.

**한 줄:** 장바구니는 "있으면 편한" 기능이지 "없으면 안 되는" 기능이 아니다. 확실한 가치는 작고 큰 가치는 미검증이라, **만들지 말지는 결국 성장 베팅을 할 의지가 있느냐**로 귀결된다 — 그 의지가 없다면 데이터는 No-go를 가리킨다.
