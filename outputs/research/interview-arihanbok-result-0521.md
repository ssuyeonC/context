- 자동확정 정책에 큰 불편 없음 — 한 타임 20팀 수용 가능한 운영 특성 덕분

## 핵심 발견 (Top 우선순위 → 후순위)

### 1. 예약 내역 테이블 UI 개선 ⭐⭐
- **구조 단순화**: 예약 상점 컬럼 제거 (불필요)
- **권장 컬럼**: 예약 코드 / 날짜 / 시간 / 이름 / 상태
- **상태 컬럼 컬러 코딩** — 가독성 향상
- **행별 컬러** — 엑셀 식 시각적 구분
- **소팅 기능** — 현재 부재
- → **데이터 가독성·내비게이션 중심의 UI 리팩토링** 영역

### 2. 스팟 상세 페이지 UI 디테일 ⭐
- **사진 포맷 세로 지원** — 현재는 가로 위주, 입력 시 자동 조정
- **본문 영역 현재가 그나마 낫다** — 큰 불만 없음
- **AI Review 요약 좋음** — 긍정적 피드백
- **리뷰 노출 강화** + **하이라이트에서 리뷰로 바로 이동** 동선
- **옵션에 사진 넣기** — 가격표/옵션의 시각적 인지도 ↑

### 3. 파트너 메모 + 익명 피드백 채널 ⭐ (신선한 아이디어)
- **어드민 우측 상단에 파트너 메모 영역**
  - 파트너가 알아서 필요한 정보 기록
  - 이 영역에서 **크리에이트립 어드민으로 직접 발송** 가능
  - **익명 발송** — 부담 없이 불편/개선 피드백 가능
- 다른 파트너에서 안 나온 **메타 피드백 채널** 아이디어

### 4. 카톡 우회는 이미 정착 — 변화 의지 낮음
- 사진 업데이트 등 콘텐츠는 **카톡으로 전달이 정착**되어 바꾸기 어려울 것이라 인지
- → 콘텐츠 직접 편집 권한에 대한 갈증 약함 (메디큐브와 유사, 투어스토리/모델로와 반대)
- 세부 사항도 주로 카톡으로 소통

### 5. 촬영 상품의 카톡 우선
- 한복 촬영 상품은 **작가와 한 번 더 연결이 필요** → 카톡이 더 적합
- 어드민에서 처리하기에 정보 흐름이 부적합한 영역

### 6. 자동확정 정책 OK (운영 특성)
- 한 타임 20팀까지 수용 가능 → 자동확정에 문제 없음
- 단, **예약 시간 관리 기능 강화** 필요 (대규모 슬롯 관리 효율)

### 7. 다중 플랫폼 통합 — 네이버로 자체 해결
- 통합 관리에 **네이버 시스템** 활용
- → 순시키와 유사 패턴 (외부 통합 도구 의존)

### 8. 브랜딩
- "크리에이트립 로고 붙이기" 언급 — (어드민/상세페이지 등 브랜딩 노출 의도로 추정, 확인 필요)

## 가설 검증/관찰

### "어드민 잘 쓰는 파트너 = UI 디테일 페인 자세히 보임"
- ✅ **검증됨** — 깊이 쓸수록 구체적 UI 페인이 누적되어 명확한 개선 제안 가능
- "스팟 상세 사진 포맷 세로 지원", "옵션 사진 넣기", "AI 리뷰 좋음", "예약 테이블 컬러 코딩" 등은 **사용량 많은 사용자만 낼 수 있는 피드백**

### "카톡 정착 = 변화 비용 인식"
- ✅ "이미 카톡으로 정착되어 바뀌기 어려울 것" — **자체적으로 변화 비용을 인식**
- → 콘텐츠 직접 편집 기능을 풀어도 **즉시 이용 전환은 안 일어날 가능성**
- 새 기능 도입 시 **온보딩/마이그레이션 설계 필요**

### "익명 피드백 채널" — 메타 욕구
- 다른 파트너는 "기능 X 개선해달라"는 직접 욕구만 표현
- 아리한복은 "파트너가 의견을 쉽게 보낼 채널 자체"를 제안 → **메타 레벨의 욕구**
- 이는 **익명성에 대한 갈증**(공개적으로 컴플레인하기 부담)도 시사
- 적용 시 다른 파트너에게도 유효할 가능성

### 운영 특성과 자동확정
- 한 타임 20팀 수용 가능 = 대규모 슬롯 = 자동확정에 친화적
- 메디큐브/모델로(1:1 시술/촬영) 같은 정밀 슬롯 운영과는 다른 운영 패턴
- → **운영 규모/특성별로 자동확정/슬롯 정책의 적정값이 다름**
