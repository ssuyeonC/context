## 인터뷰 컨텍스트

- 헤어샵 대표님 운영
- 경쟁 OTA 활발 사용: KKday(만족도 높음 + 예약 빼앗기는 우려), 클룩(분담·새벽 대응 우수), 트립닷컴(고가에도 30건+ 인입)
- **고객 유입 경로**: 인스타그램 → 가격 비교 → 크트에서 최저가로 예약
- 사업자 운영 패턴: **운전 중 핸드폰으로 예약 확인** — PC 중심 어드민에 강한 불만
- 다른 플랫폼 예약을 먼저 확인하고 크트는 늦게 보는 경우 발생

## 핵심 발견 (Top 우선순위 → 후순위)

### 1. 모바일 어드민 앱 + 푸시 ⭐⭐
- **현재 어드민이 PC형** → 운전·이동 중 사용 불가
- 결과: **다른 OTA 예약을 먼저 보고 크트는 늦게 확인** → 매출 손실
- 갈증: **파트너 어드민 앱 + 푸시 알림**
- 레퍼런스: **KKday — 관리자 어플 + 푸시 메시지**
- 모바일 환경 사용성이 본질적으로 핵심 (단순한 반응형 ≠ 앱 경험)

### 2. 고객 직접 연락 + 번역 ⭐⭐
- 현재는 톡방으로 운영팀 거치는 구조 — **밤 시간대 연락이 어려움**
- 갈증:
  - 어드민에서 **고객에게 직접 연락**
  - 메시지 입력 시 **파파고 등 자동 번역**
  - **이메일/SNS 통해 직접 연락** 가능 시스템
- 레퍼런스: **KKday — 직접 취소 + 언어별 번역 메시지 발송**
- 메디큐브와 동일 패턴 — 다이렉트 메시징 갈증

### 3. 직접 취소 + 메시지 입력 ⭐
- 어드민에 이미 있는 기능을 **모르거나 불편해서 안 씀**
- 갈증:
  - **취소 이유 설정**
  - **고객에게 발송할 메시지 입력** (+ 자동 번역)
- 레퍼런스: KKday 표준

### 4. 리뷰 작성 경험 개선 ⭐
- 현재: 시술 후 고객이 리뷰 작성까지 가는 동선이 길어 작성률 낮음
- 갈증:
  - **시술 끝난 후 버튼만 누르면 바로 리뷰 작성** 동선
  - **파트너가 어드민에서 버튼 클릭 → 유저 기기로 리뷰 작성 푸시** → 바로 작성
- 운영 메모: **예약 확정 처리를 빠르게 해야 리뷰 작성으로 이어짐** → 확정 처리 동선 자체도 단순화 필요
- 메디큐브 패턴(비회원/예약내역 안 떠서 못 씀)과는 다른 각도 — **작성 마찰 자체**

### 5. 리뷰 통제 (악플 관리) ⭐
- 갈증:
  - **악플 블러 처리**
  - **특정 고객은 악플 못 달게 처리**
- 레퍼런스: **KKday — 리뷰 삭제 가능, 악평 시 48시간 내 예약 감소 체감**
- → **리뷰가 매출에 직접 임팩트** 인식 강함
- 현재 호수도산은 모든 리뷰에 대댓글 안 다는 정책

### 6. 인스타그램 연동 ⭐
- 고객 유입 시나리오: **인스타그램(이미지)에 끌림 → 크트에서 가격 보고 예약**
- 갈증: **파트너 어드민에서 인스타그램 직접 연동**해 스팟에 노출
- → 크트 상세페이지 매력도 ↑, 외부 이탈 방지

### 7. 다건 예약 복사·일괄 처리
- 현재 크트는 **1건당 처리** → 비효율
- KKday는 한 번에 여러 건 복사 가능
- 투어스토리(50+ 상품)와는 다른 종류의 다건 페인 — 예약 단위

### 8. 비즈니스 확장 제안
- **헤어 아카데미 상품 판매 제안** — 한국 헤어시술 기법 배우러 오는 해외 수요 ↑ (퍼스널컬러 아카데미 사례 인용)
- **펌/염색 1만원 할인 같은 이벤트 제안 요청** — 크트 측에서 적극적으로 제안해달라
- 호수도산 아카데미 자체 진행 예정

### 9. 큐레이션·노출 정책 의견
- "여러 업체 밀지 말고, **최우수 업체를 깔끔하게** 미는 게 좋겠다"
- "너무 지저분한 게 많다" — 노출 정책에 대한 비판

## 가설 검증/관찰

### "예약 확인 우선순위 = 모바일 사용성에 직결"
- ✅ **검증됨** — 사업자가 PC 앞에 앉아 있지 않음 → 모바일 앱·푸시 없는 채널은 자연스레 후순위
- "다른 OTA 먼저 보고 크트는 늦게 본다"는 발언은 **모바일 부재로 인한 매출 손실**의 직접 증거

### "KKday 표준 = 헤어/뷰티 카테고리 베이스라인"
- 직접 취소+번역 / 관리자 앱+푸시 / 다건 복사 / 리뷰 통제는 호수도산의 핵심 5개 요구와 거의 일치
- → KKday 어드민은 카테고리 표준으로 자리 잡았다고 봐도 무방
- 투어스토리도 동일한 비교 프레임을 인용한 바 있음 — **OTA 표준 격차**가 횡단 패턴

### "리뷰 매출 직결 인식"
- ✅ 강하게 인식 — KKday에서 악평 시 48시간 내 예약 감소 체감
- → 리뷰 작성률 ↑ + 리뷰 품질 통제 = 헤어 카테고리의 **운영 KPI**

### "인스타 → 가격 비교 → 크트 예약" 유저 흐름
- 매력은 인스타에서, 결제는 크트에서 (최저가 매력)
- 만약 크트 상세에서 인스타 콘텐츠를 못 보면, **고객이 외부로 이탈해 다른 OTA로 빠질 위험**
- 인스타 연동은 매출 방어 도구

### 비즈니스 제안 (이벤트, 아카데미)
- 단순 어드민 개선을 넘어서 **세일즈/마케팅 협업 채널** 욕구
- → 어드민 안에 **이벤트 제안 받기/제출** 같은 영역도 검토할 만함
