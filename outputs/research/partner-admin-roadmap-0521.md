| 트랙 | 무엇 | 왜 | 비용 가설 | 임팩트 가설 |
|------|------|-----|----------|----------|
| **P0** 인지·디스커버리 | 기존 기능 노출/온보딩 | "있는데 모름" 패턴 다수 — ROI 최고 | 낮음 | 높음 |

| **P3** 권한 모델 | 파트너 유형별 자율 편집 차등 권한 | 카테고리별 욕구 스펙트럼 명확 | 높음 | 높음 |
| **P3** 리뷰 시스템 강화 | 작성 동선·통제·노출 3축 | 매출 직결 인식 강함 | 높음 | 높음 |
| **P3** CRM/고객 정보 | 여권명 통일, 입력 검증, 재방문 식별 | 다운스트림 전반에 영향 | 중~높음 | 높음 |
| **P4** 다스팟 운영 | 상품 검색, 일괄 처리, 다국어 편집 | 다스팟 파트너 한정이나 깊은 페인 | 중~높음 | 중 (해당 파트너에 한해 큼) |
| **P4** 메타·확장 | 파트너 메모, 익명 피드백, 이벤트 제안, 인스타 연동 | 협업 채널 메타 욕구 | 중 | 중~높음 (장기) |

## P0 — 즉시 (Q1 ~6주)

### P0-1. 기존 기능 인지·디스커버리 캠페인
**왜**: 알림톡, 리뷰 댓글+자동번역, 직접 취소, 상품별 스케줄, 스팟 정보 수정 요청 — 모두 이미 있는데 모르는 파트너 다수.

**무엇**:
- 어드민 첫 로그인/주기적 인앱 가이드 (사용 안 한 기능 안내)
- "체크리스트" 위젯: 알림톡 ON, 리뷰 댓글 활성화, 직접 취소 권한 확인 등
- 신규 파트너 온보딩 시 카테고리별 권장 기능 세트
- 운영팀이 카톡으로 요청 받았을 때 **"이건 어드민에서 직접 하실 수 있어요" 안내 트리거**

**관련 파트너**: 메디큐브(알림톡·리뷰댓글), 모델로(스케줄·수정요청), 호수도산(직접취소), 순시키(전반)

### P0-2. 버그픽스 (신뢰 회복)
- **모바일 예약 확정 화면 요일 오노출** (메디큐브 — 5/12 토 표시)
- **어드민 사진 수정요청 메뉴의 표시 사진 ≠ 실제 관리 사진** (모델로)
- **예약 캘린더 1년치 오픈 시 기존 차단 타임 초기화** (메디큐브) — 또는 명확한 경고
- **리뷰 작성 알림 누락** (메디큐브)

### P0-3. 알림 누락 점검
- **리뷰 작성 시 파트너 메일 알림 누락 케이스** (메디큐브 인지)
- 알림 발송 신뢰성 점검 + 대시보드로 가시화

## P1 — 단기 (Q1~Q2, 6~12주)

### P1-1. 예약 내역 테이블 리팩토링
**원천**: 아리한복 (구체적 제안)
- 컬럼 단순화: 예약 코드 / 날짜 / 시간 / 이름 / 상태
- **상태 컬러 코딩** + 행별 컬러
- **소팅 기능** 추가
- **상품/이름/날짜 검색** (투어스토리도 강력 요구 — 다스팟에 필수)

### P1-2. 어드민 모바일 사용성 1차 개선 (반응형)
- 모바일 앱(P2)을 만드는 동안 단기 응급조치
- 예약 내역·확정·취소 같은 핵심 액션을 모바일 친화로 재배치
- 순시키/호수도산 요청 1차 대응

### P1-3. 스팟 상세 UI 디테일
**원천**: 아리한복, 메디큐브
- **세로 사진 포맷 지원** + 자동 포맷 조정
- **옵션에 사진 추가**
- **하이라이트 → 리뷰 영역 빠른 이동** 동선
- **상세페이지 강조도 설정** (병원별/파트너별 토글 vs 직노출 선택)

## P2 — 중기 (Q2~Q3, 핵심)

### P2-1. 인앱 다이렉트 메시징 + 자동 번역 ⭐⭐⭐
**원천**: 메디큐브, 호수도산, 순시키 (다수)
**현재 우회**: 왓츠앱, 톡방, CX팀 카톡

**무엇**:
- 어드민에서 고객에게 직접 메시지 발송
- 메시지 입력 시 **파파고/자동 번역** 옵션 (언어 자동 감지)
- 변경/취소 시 사유+메시지 동봉 발송
- 알림톡/메일 동시 전달

**왜 P2 최우선**: 횡단 임팩트 최고. 카톡 우회의 가장 큰 트래픽 흡수.

### P2-2. 모바일 어드민 앱 + 푸시 ⭐⭐⭐
**원천**: 호수도산 (매출 손실 실증), 순시키

**무엇**:
- iOS/Android 네이티브 또는 PWA 수준
- **푸시 알림** — 신규 예약·변경·취소
- 핵심 액션만 (확인/확정/취소/메시지)

**왜 P2**: OTA 표준 격차의 가장 큰 항목. 호수도산은 이미 다른 OTA에 예약을 빼앗기는 중. 다만 비용이 매우 크므로 P2-1과 우선순위 협의 필요.

### P2-3. 수정 요청 진행 가시성
**원천**: 투어스토리 (3개월 대기), 모델로 (1개월 대기)

**무엇**:
- 수정 요청 상태: 받음 → 검토 중 → 반영 완료
- 어드민 화면 + 알림으로 단계별 통보
- 카톡 우회를 어드민으로 끌어오는 핵심 신뢰 회복 장치

### P2-4. 직접 취소 + 메시지 + 번역 (P2-1과 연계)
**원천**: 호수도산 (KKday 표준)
- 취소 사유 선택 + 고객에게 발송할 메시지 (번역 동봉)

### P2-5. 상품/옵션별 스케줄 분리 관리
**원천**: 모델로 (네이버 플레이스 참고)
- 통합 메뉴 → 상품/옵션 단위 ON/OFF
- 상품별/시간대별 실시간 현황 뷰

### P2-6. 리뷰 작성 동선 단순화
**원천**: 호수도산
- 시술 완료 → 푸시 → 즉시 작성
- 파트너 어드민에서 "리뷰 요청" 버튼 → 유저 기기 푸시

## P3 — 중장기 (Q3~Q4, 구조 변경)

### P3-1. 콘텐츠 자율 편집 권한 (파트너 유형별 차등) ⭐
**원천**: 투어스토리(전면 자율 요구), 모델로(사진만), 호수도산(인스타), 메디큐브(부담)

**무엇**:
- **권한 등급제** 도입
  - L1 자율: 가격·일정·콘텐츠 자율 (검수는 가격/썸네일 등 민감 영역만) — 다스팟 검증된 B2B 파트너
  - L2 일부 자율: 사진/SNS만 자율, 텍스트는 검수 — 이미지 중심 카테고리
  - L3 검수 유지: 모두 검수 후 반영 — 의료·언어 민감
- 파트너 신청 + 운영팀 승인 → 등급 이동
- 자율 편집 시 **롤백/이전 버전** 기능 동반 (잘못 수정 부담 완화)

### P3-2. CRM·고객 정보 정확성
**원천**: 메디큐브, 순시키
- **여권명 기준 통일** (영문 입력 표준화)
- 전화/이메일 **2회 입력 검증** UX
- SNS ID 공개여부/유효성 입력 단계 안내
- **재방문 고객 자동 표시** (등록번호 기반)
- 신규 정산 시스템 표기와 동일화

### P3-3. 리뷰 시스템 강화
**원천**: 호수도산, 메디큐브, 아리한복
- **비회원 리뷰 작성 허용** (예약 코드 기반)
- **악플 블러 / 특정 고객 차단**
- **리뷰 작성 알림** 신뢰성
- AI 리뷰 요약 강화 (아리한복 긍정)

### P3-4. 동행 예약 처리
**원천**: 메디큐브
- 예약 시 **동행 여부 안내/식별** 정보 추가
- 동일 시간·날짜 다수 예약 = 동행 묶음 표시
- 동행 분산 예약 방지 UX

### P3-5. 다국어 자율 편집 + AI 자동 번역
**원천**: 투어스토리, 모델로
- 자국어 작성 → AI 자동 번역 → 필요 시 수동 보정
- 다국어 일괄 적용

## P4 — 장기 (Q4+, 메타·확장)

### P4-1. 다스팟 운영 도구
**원천**: 투어스토리(50+), 호수도산
- **상품 ID/명 검색** (P1-1과 연계해 즉시 가능)
- **일괄 작업** — 가격 인상·시즌 종료·다건 복사
- 다국어 예약 자동 분류/연동

### P4-2. 인스타그램 직접 연동
**원천**: 호수도산
- 파트너 어드민에서 인스타 계정 연동
- 스팟 상세에 인스타 콘텐츠 노출
- 외부 이탈 방지

### P4-3. 파트너 메모 + 익명 피드백 채널
**원천**: 아리한복 (메타 욕구)
- 어드민 우측 상단 메모 영역
- 익명으로 운영팀에 발송 가능
- 파트너 보이스 수집 채널 자체 강화

### P4-4. 비즈니스 협업 채널
**원천**: 호수도산
- 운영팀이 이벤트 제안 받는/주는 채널
- 신규 상품 카테고리(헤어 아카데미 등) 제안

### P4-5. 타플랫폼 통합 뷰
**원천**: 순시키 (가장 큰 욕구)
- 비용·복잡도 매우 큼 — 자체 통합 도구(네이버 등) 사용 파트너 우선 검증 필요
- 우선순위 낮음 — 다른 P0~P3 처리 후 검토
