## 한 줄 요약

> "어드민은 잘 쓰고 있고 어드민 자체의 **UI/UX 개선**과 **상세페이지 UI 디테일**에 대한 구체적 제안 다수. **카톡 우회가 이미 정착**되어 콘텐츠 직접 수정 권한에는 큰 갈증 없음. **파트너 메모/익명 피드백 채널** 등 신선한 아이디어 제시."

## 파트너가 실제로 겪는 문제

> **means-ends chain 매핑**: 어드민이 카톡보다 "명백히 더 나은 경험"이 되려면 아래 문제를 빠르고 가시적으로 해결해야 함.
>
> **본질 한 문장**: *이미 콘텐츠 생산자·운영자 역할까지 자임하는 파워유저에게는, 어드민이 그 작업을 받아낼 수 있는 UI 완성도와 업로드 편의성이 본질이다. 자율 권한 자체보다 우회 비용 없는 일상 도구화가 우선.*
>
> **이 파트너의 특수성** — 한복 시장 경쟁 격화 환경에서 이미지로 차별화하는 비즈니스 + 디지털 네이티브 + 마케팅 도구 이해도 높음 (이미 어드민의 수수료 설정으로 노출 순위 조정까지 활용):
>
> ```
> [생산]                          [어드민]
> 파트너가 이미 규격·포맷 맞춰    →    UI 완성도·업로드 편의성이
> 손수 콘텐츠 편집·전달 (희귀 케이스)     이 작업을 받아들이지 못함
>                                          │
>                                          ↓
>                          카톡 우회가 이미 정착 → 자율 권한 풀어도 즉시 전환 X
>                                          ↓
>                          신규 기능보다 UI 완성도 + 마이그레이션 설계가 우선
> ```
>
> 자율 권한 차원의 **3극 위치**: 메디큐브(부담) ↔ 투어스토리·모델로(요구) ↔ **아리한복(의지 X + 본인이 이미 생산)**. 종합본 2.4 차등 정책의 세 번째 극.

### P1. 예약 테이블 UI 미완성 — 매일 보는 화면의 가독성·내비게이션 부족 `명시` (UI 완성도)
- **본질**: 가장 빈번하게 보는 예약 테이블이 컬럼 단순화·컬러 코딩·소팅·행별 시각 구분 등 기본 데이터 가독성 도구가 부족
- **현재 처리 방식**: 어드민에서 직접 사용 중 (활용도 높음) — 페인을 의식하며 견디는 상태
- **비용**: 매일 누적되는 인지 부담, 운영 효율 저하 — 사용량 많은 사용자에게서만 노출되는 페인
- **근거**: "예약내역 테이블 구조 변경되면 좋을 듯 — 예약 상점이 굳이 없어도 될 듯 / 예약 코드 - 날짜 - 시간 - 이름 - 상태 / 상태는 가독성 높이기 위한 컬러 / 엑셀 행 별 컬러 / 소팅 기능"

### P2. 사진 업로드·콘텐츠 워크플로우 편의성 부재 — 생산은 하는데 시스템이 못 받음 `명시` (생산 워크플로우)
- **본질**: 본인이 이미 규격·포맷에 맞춰 콘텐츠를 손수 편집해서 전달하는데, 어드민이 그 작업을 받아낼 수 있는 업로드 편의성(세로 포맷·자동 조정 등)을 갖추지 못함
- **현재 처리 방식**: 손수 편집 후 카톡으로 전달 → 운영팀이 어드민에 반영
- **비용**: 파트너가 두 번 일하는 구조 (생산 + 전달 우회), 운영팀에 콘텐츠 반영 부담 떠넘김
- **근거**: "스팟 상세에 이미지 넣을 때 사진 포맷 세로로 넣을 수 있으면 좋을 듯 / 사진입력 시 포맷 자동으로 조정될 수 있도록 편집" / "사진 업데이트 등 컨텐츠는 카톡으로 전달"

### P3. 상세페이지 UI 디테일 — 시각적 차별화 도구 부재 `명시` (UI 완성도)
- **본질**: 한복 시장 경쟁 격화 환경에서 이미지가 차별화 무기인데, 옵션 사진·세로 포맷·하이라이트→리뷰 동선 등 시각적 차별화 도구가 부족
- **현재 처리 방식**: 본문 영역은 현재가 그나마 낫다고 평가하면서도, 옵션·하이라이트 등 주요 인지 지점은 개선 욕구 강함
- **비용**: 경쟁 환경에서 이미지로 차별화할 기회 손실
- **근거**: "옵션에 사진을 넣을 수 있도록 하면 좋겠음" / "리뷰가 잘 보이는 게 좋음 / 하이라이트 영역에서 리뷰로 바로 이동할 수 있으면 좋을 듯" / "AI Review 요약 좋음"

### P4. 대규모 슬롯 운영 도구 부재 — 한 타임 다수 수용 운영 패턴 `명시` (운영 패턴)
- **본질**: 한 타임 20팀 수용 가능한 운영 → 자동확정에 친화적이지만, 대규모 슬롯을 효율적으로 관리할 수 있는 예약 시간 관리 기능이 부족
- **현재 처리 방식**: 자동확정 운영 + 슬롯 관리는 현재 도구로 견딤
- **비용**: 대규모 슬롯 운영의 정밀도/효율 한계 — 메디큐브/모델로의 1:1 시술·촬영 슬롯과 다른 카테고리
- **근거**: "자동확정에 따른 문제는 없음 — 한 타임에 20팀을 받을 수 있어서 괜찮음 (예약 시간 관리 기능 강화 필요)"

### P5. 콘텐츠 자율 편집 권한 — 잠재적이지만 즉시 갈증 X `잠재` (자율)
- **본질**: 자율 권한 자체에 대한 갈증은 약함 — 카톡으로 정착되어 변화 비용을 본인이 인지
- **현재 처리 방식**: 카톡으로 운영팀에 콘텐츠 전달 → 정착됨
- **비용**: 권한을 풀어도 즉시 전환 안 일어날 가능성 → 신규 기능보다 **온보딩·마이그레이션 설계**가 권한 부여보다 우선
- **근거**: "사진 업데이트 등 컨텐츠는 카톡으로 전달 — 이미 카톡으로 정착되어 바뀌기 어려울 듯"

### P6. 다중 플랫폼 통합 — 외부(네이버) 자체 해결 `잠재` (통합)
- **본질**: 여러 플랫폼 운영하는데 통합은 네이버 시스템 사용. 어드민 갈증으로는 약함, 다만 자체 통합 운영이 곧 장기 운영 부담의 일부
- **현재 처리 방식**: 네이버 시스템 자체 활용
- **비용**: 외부 도구로 해결 중이라 즉시 페인은 낮음. 장기적으로 어드민이 흡수 가능한 영역
- **근거**: "여러 플랫폼을 쓰기 때문에 하나로 통합하는데 이를 네이버 시스템을 씀"

### P7. 메타 피드백 채널 — 익명 피드백 + 파트너 메모 `명시` (메타)
- **본질**: 단일 기능 개선을 넘어 **파트너 ↔ 크트 협업 채널 자체**에 대한 욕구. 익명성에 대한 갈증(공개적으로 컴플레인하기 부담)도 시사
- **현재 처리 방식**: 부재 (현재 채널 없음)
- **비용**: 파트너의 의견이 시스템에 잡히지 않음 → 다른 파트너에게도 횡단 적용 가능한 메타 욕구
- **근거**: "파트너 어드민 우측 상단에 파트너가 메모를 입력할 수 있는 영역 / 파트너가 알아서 필요한 정보 메모하는 용도 / 이 영역을 통해 어드민에게 발송할 수도 있도록 / 익명으로 발송되는 게 좋을 듯"

### 통합 해석

P1·P3은 **UI 완성도 축** (매일 보는 화면 + 시각적 차별화), P2·P4는 **운영 워크플로우 축** (생산 워크플로우 + 대규모 슬롯), P5·P6은 **잠재 페인** (자율·통합은 즉시 갈증 X), P7은 **메타** (협업 채널).

**메타 관찰 1 — 파워유저 = 얼리어답터 후보**: 본인이 어드민의 수수료 설정으로 노출 순위 조정까지 활용 중. 툴/서비스 이해도가 높은 희귀 케이스. → **이 파트너의 페인을 해결하면 결과물이 다른 파트너에게 트리클다운될 가능성**. 어드민의 디자인·기능 베이스라인을 검증할 "기준 파트너" 후보.

**메타 관찰 2 — 자율 권한 차원의 3극**: 메디큐브(부담) / 투어스토리·모델로(요구) / 아리한복(의지 X + 본인이 이미 생산). 세 번째 극의 시사점은 "권한 풀기 = 솔루션"이 아니라 **"카톡 우회의 마이그레이션 설계"가 우선**이라는 점. 종합본 0.3의 "어드민 자체 개선 + 제휴팀 능동적 리다이렉트"가 함께 가야 한다는 원칙의 강한 증거.

**메타 관찰 3 — UI 디테일 페인은 깊이 쓰는 사용자에게서만 노출**: 종합본 2.10 검증 사례. 어드민 활용도를 끌어올리면 UI 디테일 페인도 함께 노출 → **지속적 UI 폴리싱 체계** 필요.

- 자동확정 정책에 큰 불편 없음 — 한 타임 20팀 수용 가능한 운영 특성 덕분

## 핵심 발견 (Top 우선순위 → 후순위)

### 1. 예약 내역 테이블 UI 개선 ⭐⭐
- **구조 단순화**: 예약 상점 컬럼 제거 (불필요)
- **권장 컬럼**: 예약 코드 / 날짜 / 시간 / 이름 / 상태
- **상태 컬럼 컬러 코딩** — 가독성 향상
- **행별 컬러** — 엑셀 식 시각적 구분
- **소팅 기능** — 현재 부재
- → **데이터 가독성·내비게이션 중심의 UI 리팩토링** 영역

### 2. 스팟 상세 페이지 UI 디테일 ⭐
- **사진 포맷 세로 지원** — 현재는 가로 위주, 입력 시 자동 조정
- **본문 영역 현재가 그나마 낫다** — 큰 불만 없음
- **AI Review 요약 좋음** — 긍정적 피드백
- **리뷰 노출 강화** + **하이라이트에서 리뷰로 바로 이동** 동선
- **옵션에 사진 넣기** — 가격표/옵션의 시각적 인지도 ↑

### 3. 파트너 메모 + 익명 피드백 채널 ⭐ (신선한 아이디어)
- **어드민 우측 상단에 파트너 메모 영역**
  - 파트너가 알아서 필요한 정보 기록
  - 이 영역에서 **크리에이트립 어드민으로 직접 발송** 가능
  - **익명 발송** — 부담 없이 불편/개선 피드백 가능
- 다른 파트너에서 안 나온 **메타 피드백 채널** 아이디어

### 4. 카톡 우회는 이미 정착 — 변화 의지 낮음
- 사진 업데이트 등 콘텐츠는 **카톡으로 전달이 정착**되어 바꾸기 어려울 것이라 인지
- → 콘텐츠 직접 편집 권한에 대한 갈증 약함 (메디큐브와 유사, 투어스토리/모델로와 반대)
- 세부 사항도 주로 카톡으로 소통

### 5. 촬영 상품의 카톡 우선
- 한복 촬영 상품은 **작가와 한 번 더 연결이 필요** → 카톡이 더 적합
- 어드민에서 처리하기에 정보 흐름이 부적합한 영역

### 6. 자동확정 정책 OK (운영 특성)
- 한 타임 20팀까지 수용 가능 → 자동확정에 문제 없음
- 단, **예약 시간 관리 기능 강화** 필요 (대규모 슬롯 관리 효율)

### 7. 다중 플랫폼 통합 — 네이버로 자체 해결
- 통합 관리에 **네이버 시스템** 활용
- → 순시키와 유사 패턴 (외부 통합 도구 의존)

### 8. 브랜딩
- "크리에이트립 로고 붙이기" 언급 — (어드민/상세페이지 등 브랜딩 노출 의도로 추정, 확인 필요)

## 가설 검증/관찰

### "어드민 잘 쓰는 파트너 = UI 디테일 페인 자세히 보임"
- ✅ **검증됨** — 깊이 쓸수록 구체적 UI 페인이 누적되어 명확한 개선 제안 가능
- "스팟 상세 사진 포맷 세로 지원", "옵션 사진 넣기", "AI 리뷰 좋음", "예약 테이블 컬러 코딩" 등은 **사용량 많은 사용자만 낼 수 있는 피드백**

### "카톡 정착 = 변화 비용 인식"
- ✅ "이미 카톡으로 정착되어 바뀌기 어려울 것" — **자체적으로 변화 비용을 인식**
- → 콘텐츠 직접 편집 기능을 풀어도 **즉시 이용 전환은 안 일어날 가능성**
- 새 기능 도입 시 **온보딩/마이그레이션 설계 필요**

### "익명 피드백 채널" — 메타 욕구
- 다른 파트너는 "기능 X 개선해달라"는 직접 욕구만 표현
- 아리한복은 "파트너가 의견을 쉽게 보낼 채널 자체"를 제안 → **메타 레벨의 욕구**
- 이는 **익명성에 대한 갈증**(공개적으로 컴플레인하기 부담)도 시사
- 적용 시 다른 파트너에게도 유효할 가능성

### 운영 특성과 자동확정
- 한 타임 20팀 수용 가능 = 대규모 슬롯 = 자동확정에 친화적
- 메디큐브/모델로(1:1 시술/촬영) 같은 정밀 슬롯 운영과는 다른 운영 패턴
- → **운영 규모/특성별로 자동확정/슬롯 정책의 적정값이 다름**

| 항목 | 순시키 | 메디큐브 | 모델로 | 투어스토리 | 아리한복 |
|------|--------|---------|--------|----------|---------|
| 어드민 활용도 | 높음 | 중간 | 부분 | 일정/마감만 | **높음** |
| 카톡 우회 빈도 | 중간 | 높음 | 매우 높음 | 매우 높음 | **중간 (정착, 만족)** |
| 콘텐츠 직접 수정 의향 | 약함 | 부담 | 사진만 강함 | 강함 | **약함 (변화 비용 인식)** |
| 핵심 페인 | 채널 통합, 재방문 식별 | 정보 정확성, 다이렉트 메시징, 동행 | 상품별 스케줄, 사진 | 자율 권한, 검색, 다국어 | **UI 디테일, 메모/피드백 채널** |
| 다중 플랫폼 통합 | 갈증 강함 | 언급 X | 언급 X | 자체 시스템 | **네이버로 해결** |

→ 아리한복은 어드민 잘 쓰는 그룹 안에서도 **UI 완성도/메타 피드백 욕구**가 두드러지는 유형

## 어드민에 없지만 필요한 기능 후보 (아리한복 핵심)

1. **예약 내역 테이블 리팩토링** — 컬럼 단순화, 컬러 코딩, 행별 컬러, 소팅 (즉시 효과 큼)
2. **세로 포맷 사진 지원** — 자동 포맷 조정
3. **옵션에 사진 넣기**
4. **AI 리뷰 요약 + 하이라이트→리뷰 빠른 이동 동선**
5. **파트너 메모 영역 (어드민 우측 상단)**
6. **익명 피드백 발송 채널** — 메타 욕구, 횡단 적용 가능
7. **대규모 슬롯 관리 강화** — 한 타임 다수 수용 운영용
