# 파트너 어드민 개선 — 미팅 공유 요약

> 첨부: `partner-admin-roadmap-0521.md` (상세 로드맵)

---

## 1. 개선의 이유

> **어드민 사용의 일상화 + 카톡 사용의 비일상화**

- **목표**: 제휴팀의 시간이 **반응형 트랜잭션 처리 → 관계·전략·영업**으로 재배분 (워크로드 감소가 아니라 **시간 가치의 이동**)
- **현 상태**: 6개 파트너 인터뷰 결과, 파트너는 일상 업무(예약 변경·콘텐츠 수정·고객 안내)를 **카톡으로 우회** 중. 이는 게으름이 아니라 어드민의 가시성·응답속도 부족에 따른 **합리적 채널 선택**의 결과
- **경쟁 환경**: 헤어/뷰티·일일투어 카테고리에서 KKday 등 경쟁 OTA가 이미 카테고리 표준. 호수도산 케이스 = 모바일 부재로 다른 OTA로 예약 이탈 **실증 중**

## 2. 개선의 방향

### 채널 분리 원칙
| 구분 | 채널 | 어떤 작업 |
|------|------|---------|
| **일상·주기** | 어드민 | 예약 확인·확정·취소, 스케줄, 가격·메뉴, 콘텐츠, 고객 메시지, 리뷰 응대 |
| **비일상·예외** | 카톡 (비상연락망) | 신규 상품 등록, 분쟁, 비즈니스 전략·이벤트 제안, 시스템 장애, 권한·계약 |

### 두 갈래로 흡수
- **자율 처리 흡수** — 직접 처리 의향 있는 파트너 (예: 투어스토리·모델로·호수도산)
- **요청 채널 흡수** — 직접 처리는 부담스러운 파트너 (예: 메디큐브) — 어드민으로 요청 + **진행 가시성**으로 카톡 대체

### 제휴팀 운영 변화 동반 필수
- 어드민 개선만으로는 카톡 트래픽이 자동으로 옮겨지지 않음
- 카테고리 매니저가 **능동적 리다이렉트** ("이건 어드민에서 직접 하실 수 있어요") + **신규 기능 1:1 안내(영업)**
- 카톡 요청 유형 분기 인터뷰로 정성 추적 (카톡 데이터 직접 수집 불가 한계 인정)

## 3. 개선의 항목

### 축 1. 어드민·유저페이지 신뢰성·사용성 강화
- **1-a 신뢰성 회복**: 버그픽스 (모바일 요일 오노출 · 캘린더 차단 초기화)
- **1-b 디스커버리·온보딩**: 기존 기능 노출 (알림톡·리뷰 댓글·직접 취소 등 "있는데 모름") + **'상품별 예약 시간 관리' 권한 확대**
- **1-c UIUX 폴리싱**: 예약 내역 테이블 리팩토링, 변경/취소 메시지 동봉, 수정 요청 진행 가시성, 사진 업로드 편집, 예약 리스트 일괄 복사, 예약 취소 자동승인 등
- **1-d 유저페이지 개선**: 입력 검증(전화·이메일·여권명), 재방문 자동 표시, 가격 인지 강화, 옵션 정보 노출 개선

### 축 2. 신규 기능 추가
- **2-a-1 ★★★ 고객 ↔ 파트너 다이렉트 메시징 + 자동 번역** (예약 시 특이사항 사전 소통)
- **2-a-2 기타 신규**: 파트너 알림 채널 확장, 파트너 메모+제휴팀 메시지, 동행 예약 처리, 다국어 자율 편집+AI 번역, 리뷰 작성 유도·관리, 인스타그램 자발 연동, 다스팟 운영 도구
- **2-b 카테고리 특화**: 피부과 '시술 정보/수가표 관리'와 같은 결의 카테고리별 1급 기능 (일일투어 itinerary, 사진 스튜디오 상품 소개 관리 등) — 호흡 길게

### 축 3. 모바일 환경 최적화
- **v1**: 예약 관리 + 알림 (사용 파트너 알림톡 OFF 전환)
- **v2**: DM 기능 (어드민 동일 사용, 2-a-1과 정렬)
- PWA vs 네이티브 — 개발자 논의 필요 (열린 결정)

### 장기 후보 (호흡 길게)
- **L-1 타플랫폼 예약 통합 뷰** (순시키)
- **L-2 악플 블러 / 작성자 차단** (호수도산) — 정책 프레임 정립 선행

## 4. 핵심 액션 (첫 90일)

| | 트랙 A (제품) | 트랙 B (제휴팀) |
|---|---|---|
| **Week 1-2** | 버그픽스, 알림 점검 | 응답 템플릿, 카테고리 매니저별 인터뷰 설계, 카테고리별 파트너 비중 데이터 |
