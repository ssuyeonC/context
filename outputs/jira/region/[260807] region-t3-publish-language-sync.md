# T3 — region 공개 상태 언어 간 동기화 (폐기)

**상태** — 폐기. 최신 정본은 `[260910] region-phase2-t1-entity-structure.md`(COM-2633)

## 배경

- 과거에는 언어별 공개 상태의 불일치를 막기 위해 모든 언어를 함께 공개하는 방식을 검토
- REGION 콘텐츠가 언어별로 독립 관리되고 번역 검수 시점도 서로 달라 전 언어 동시 공개는 미완성 번역 노출 위험 존재
- P2-T1에서 공개 상태를 언어별로 독립 관리하고 미번역 언어 폴백을 제공하지 않는 것으로 최종 확정

## 최신 결정

- 운영자는 선택한 언어 번역의 공개 상태만 변경 가능
- 특정 언어의 공개 상태 변경은 다른 언어 번역에 영향 없음
- 요청 언어의 번역이 없거나 비공개이면 다른 언어로 대체 노출하지 않음
- 직접 상세 URL 접근을 포함한 목록·필터·지도·검색·상세 조회에 같은 언어별 공개 조건 적용
- 전 언어 일괄 공개 토글과 미번역 언어 폴백은 구현하지 않음

## 수용 조건

- 특정 언어 번역 공개 시 다른 언어의 공개 상태가 유지됨
- 요청 언어 번역이 없거나 비공개이면 해당 REGION이 노출되지 않음
- 전 언어 동기화 또는 대표 언어 폴백 동작이 존재하지 않음
