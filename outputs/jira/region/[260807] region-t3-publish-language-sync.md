# T3 — region 공개 상태 언어 간 동기화

**요약** — region 공개 상태를 언어 간 동기화한다. 노출을 위한 필수 선행은 아니며(동기화 없이도 노출 가능), 언어별로 공개 상태가 어긋나는 것을 막는 일관성 개선

## 배경
- 현재 공개가 **언어별(`region_translation.is_publish`)로 흩어져** 있어, 한 언어는 공개인데 다른 언어는 비공개로 어긋날 수 있음
- `region_translation`에 **언어별 편집 콘텐츠(description·seo)** 가 있어, 전 언어 동시 공개 시 미번역 언어 노출을 고려해야 함
- 노출 자체는 T2로 가능 — 본 건은 **공개 상태 일관성 개선**에 한정

## 구현
### 유저 플로우
- 관리자가 region을 공개하면 **전 언어가 함께 공개**됨(언어별 개별 공개 아님)
- 관리자가 공개를 내리면 **전 언어가 함께 비공개**
- 유저는 미번역 언어에서도 폴백으로 정상 노출받음

### 프론트엔드 요구사항
- region 공개 토글을 **region 단위**로 노출(언어별 개별 토글 대체)
- 필수 언어셋 콘텐츠 미완성 시 공개 경고 표기

### 백엔드 요구사항
- **공개 언어 동기화** — 공개 토글이 **전 언어 `region_translation.is_publish`를 일괄 세팅**(write-time 동기화)
- **미번역 언어 폴백** — 콘텐츠 미완성 언어는 대표 언어(ko)로 폴백 노출, 또는 필수 언어셋 완성 검증 후 공개
- (선택·후속) region-level 단일 공개 플래그로 승격 — 현재 `is_publish`를 읽는 다수 경로 정리 동반

## 수용 조건
- region 공개 시 **전 언어 공개 상태 동기화**(언어 간 어긋남 0)
- 미번역 언어도 폴백으로 정상 노출
