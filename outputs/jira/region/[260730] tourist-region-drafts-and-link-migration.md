### 1-2. 방법 — "수동 이관"이 아니라 **DL당 스크립트 일괄 UPDATE** 가능

스펙은 "블로그·어학당은 legal_code가 없어 자동 도출 불가 → 소속 구로 **수동 이관**"이라 했으나, **소속 구는 그 DL의 스팟 분포(home_gu, §2)로 도출된다.** 한 DL의 블로그·유저블로그·어학당 링크는 전부 같은 소속 구로 가므로:

```
UPDATE blog_has_category      SET category_code = {home_gu_DL_code} WHERE category_code = {관광지_DL_code}
UPDATE user_blog_has_category SET category_code = {home_gu_DL_code} WHERE category_code = {관광지_DL_code}
UPDATE language_course        SET detail_location_category_id = {home_gu_DL_code} WHERE detail_location_category_id = {관광지_DL_code}
```

→ **DL당 일괄 UPDATE 스크립트.** 관광지 DL이 REGION이 되는 33개(A9+B24)면 그 DL의 blog·user_blog에 **`representative_region_id` = 대응 REGION 세팅도 함께**(지역값 CITY+REGION 노출·granularity 보존, §1-1 ✅). 진짜 수동 검토는:
- **스팟 0이라 home_gu 미도출 12개 DL**(§3-3) — 이름 기반 수동 지정.
- **소속 구가 분할·오배정된 DL**(§3-1) — 대표 구 확정 후 스크립트.

블로그·유저블로그·어학당은 legal이 없어 스팟처럼 개별 재도출은 안 되지만, **"DL 전체를 한 구로"** 옮기는 것이라 DL 단위 매핑 1개면 충분하다.

## 2. 구·법정동 초안 — 비-행정구 103개 전량 pre-run

각 DL의 스팟 `legal_location_legal_code`(8자리 법정동) 분포:
- **home_gu** = 스팟 최다 시군구(앞 5자리) + 스팟수 + 점유율%. → REGION 소속 구 초안.
- **오배정 후보** = 그 외 시군구(스팟수). 경계 걸침이거나 오태깅 → 검수.
- **핵심 법정동** = 스팟 밀집 법정동 top4. → REGION 법정동 선택 초안.
