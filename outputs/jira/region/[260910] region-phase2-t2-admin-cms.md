# P2-T2 — /region 어드민 CMS (CITY·REGION 콘텐츠 메타 + 이동 편집 + 카테고리 순서)

**요약** — `/region` 어드민에 유저페이지가 쓸 콘텐츠 메타(도시·지역 카드메타·이동 편집·주변 역·추천 대상·카테고리 순서)를 채우는 CMS를 만든다. **선행: P2-T1 · Phase 1 T2·T3**

## 배경

- 현재 `/region` 어드민은 스팟 직접 연결·플레이스 연결 등 **폐기 대상 필드**가 섞여 있고, 유저페이지가 필요로 하는 카드메타(히어로 이미지·태그·설명)·이동 정보·추천 대상을 담을 구조가 없음
- 개편 IA의 유저페이지(축②)는 이 어드민이 채운 콘텐츠 메타를 데이터 소스로 삼으므로, 어드민이 **선행**해야 페이지가 성립(생성=어드민, 스크립트 아님)
- P2-T1에서 정의한 하나의 Region + 복수 번역 구조를 전제로, `/region` 어드민에서 언어 공통 정보와 언어별 이름·콘텐츠·공개 상태를 구분하여 편집
- 초기 백필은 텍스트 계열 AI 초안 + 히어로 이미지 실사진 소싱(별도)

## 구현

### 유저 플로우

- 운영자는 `/region` 어드민에서 **지역(REGION) 탭 / 도시(CITY) 탭** 두 레이어를 전환하며 편집
- 운영자는 한국어로 생성된 지역의 상세 화면으로 이동하여 언어별 번역을 추가·편집
- 운영자는 지역 상세에서 선택한 언어의 태그·설명을 채우고 **공개**로 전환, 해당 언어 필수값 미충족 시 공개 불가
- 운영자는 부모 도시(CITY) 카드메타가 없으면 선택한 언어의 지역을 **공개할 수 없음** — 안내와 함께 도시 메타 편집 화면으로 유도
- 운영자는 도시 관리 화면에서 **도시쌍·지역쌍 이동 정보**를 한 곳에서 입력 — 한 번 입력하면 상대 페이지에도 자동 반영
- 운영자는 도시 상세·지역 상세 각각에서 **카테고리 섹션 순서**를 재정렬(묶기 없이 순서만)
- 지역명은 언어 탭별 번역값으로 관리하고, slug는 영문 지역명에서 자동 생성하여 읽기 전용으로 노출

### 프론트엔드 요구사항 [어드민 · 지역(REGION) 탭]

- **지역 목록** — 순서(도시 페이지 '구역 그리드' 노출 순서 전용, 드래그·↑↓·순서번호)·ID·현재 조회 언어의 지역명·작성자·현재 조회 언어의 **공개 여부**·**노출**(필수 메타 충족 여부 뱃지)·삭제. 순서는 대표 region 선정에는 쓰지 않음
- **언어 탭** — 번역 유무·공개 상태·AI 번역 여부를 언어별로 표시, 번역이 없는 언어 선택 시 **번역 추가** 진입 노출
- **번역 추가** — 원본 언어를 선택해 복사하거나 AI 번역으로 생성, AI 번역은 기본 비공개 상태로 생성
- **공개 토글** — 어드민 명칭을 **공개**로 통일하고 선택한 언어 번역에만 적용, 다른 언어의 공개 상태는 유지
- **활성화 가드** — 부모 도시 카드메타(대표이미지·태그·설명)와 선택 언어의 필수 메타 충족 시 공개 가능, 미충족 시 **"부모 도시 {도시명} 카드메타가 없어 이 지역을 공개할 수 없어요"** + 부족 메타 칩 + **"도시(CITY) 메타 편집 →"** 링크. "REGION만 켜고 도시 메타 누락" 고아 상태 구조적 차단
- **지역 기본 정보** — 선택 언어의 지역명·생성자·공개 토글. 부모 도시 미활성 시 공개 토글 옆 **"부모 도시 카드메타 없음 → 공개 불가"**
- **지역 메타정보 입력**(선택 언어 공개 게이트 = 히어로 이미지·태그·설명):
  - **히어로 이미지**(활성화 필수) — 지역 상세 상단 대표 이미지(풀폭). 기존 리스트 이미지 228×128 규격을 이 필드로 교체
  - **태그**(활성화 필수) — **최대 3개**. 예: 쇼핑·K-뷰티·코엑스
  - **한 줄 소개** — 유저페이지 h1 바로 아래 강조 문구
  - **대표 키워드**(선택) — 태그형 입력
  - **지역 설명**(활성화 필수) — SEO 에디토리얼 인트로(thin 방지)를 채우는 필드
  - **slug 입력 필드 없음** — 영문 지역명에서 자동 생성(§ 공통·시스템)
  - 우상단 **🌐 자동번역** — 원본 언어의 태그·한 줄 소개·설명을 선택 언어로 자동번역, 생성 결과는 기본 비공개
- **지역 범위(상세지역 연결 · 법정동 선택)**:
  - 상세지역(구) 다중 선택 + 구별 법정동 체크리스트(구 코드 prefix로 자동 도출·읽기 전용)
  - 상위 도시(시도)는 구 선택 시 자동 채움(읽기 전용)
  - 저장 차단: ① 서로 다른 시/도의 구 혼합 → **"서로 다른 도시의 구를 함께 담을 수 없어요"** ② 한 도시의 상세지역(구) 전부 선택 → **"도시 전체 범위의 지역은 만들 수 없어요. 상세지역을 하나 이상 제외해 주세요."**
  - **법정동 미선택 = 구 전체 범위**(Phase 1 T2 확정 규칙) — '전부 해제 차단'은 적용하지 않음
- **이동 정보(주변 지하철역)** — 호선 선택 → 해당 호선 연결 지하철역 선택 → 부가설명 입력 순. 한 역이 여러 호선이면 호선별로 행을 나눠 등록. **부가설명**은 유저페이지 역 행 우측에 노출되는 짧은 설명(예: **강남 중심 환승**), 자동번역 대상. 자동 추천·랭킹 없음
- **추천 대상(persona)** — 카드 단위(라벨·설명·관련 스팟 최대 3개)·추가/삭제/순서 변경. **미입력 시 유저페이지에서 이 섹션 자체 미노출**
- **카테고리 순서(지역 상세)** — 대카테고리 순서 + 각 대카 내 중카테고리 순서(중첩 리스트, 드래그·↑↓). 묶기(grouping) 없음. 도시 상세와 완전 독립(상속 없음). 미설정 시 기본값 폴백(대카=home-nav priority / 중카=category.priority)
- **필드 책임 분리** — slug·히어로 이미지·법정동·주변역·카테고리 순서·이동쌍은 언어 공통, 지역명·태그·한 줄 소개·설명·SEO·persona 라벨/설명·역 부가설명은 선택 언어 번역에만 적용
- 기존 **상세 지도 카드 노출** 토글은 제거, 지도 폴리곤은 선택 법정동 union으로 자동 도출

### 프론트엔드 요구사항 [어드민 · 도시(CITY) 탭]

- **도시 목록** — 도시명·**자식 REGION 수**·**유저 그리드 노출**(카드메타 3종 충족 여부). 자식 REGION 없는 도시는 목록에 아예 미등장(2단 게이트 ①)
- **도시 메타정보 입력**(활성화 게이트 = 대표이미지·설명·태그) — 도시명(읽기 전용)·**대표 이미지***·**설명***·부가설명(선택)·**태그***(최대 3개)·🌐 자동번역. **slug 입력 필드 없음**
- **이동 편집(도시쌍 + 지역쌍 · 방향 무관)** — 한 화면에서 두 영역 관리:
  - **도시쌍** — 조회 도시(고정) ↔ 다른 도시(CITY). 한 쌍에 **수단·소요시간(분) 복수** 등록(예: 서울↔부산 = 기차(KTX/SRT) 150·비행기 60·고속버스 260). 수단 enum = 비행기·기차(KTX/SRT)·고속버스·택시
  - **지역쌍** — 이 도시의 REGION ↔ REGION. 수단 enum = 지하철·버스·도보·택시. 소요시간(분). 이 도시에 REGION이 없으면 **"이 도시에 등록된 REGION이 없어 지역쌍을 만들 수 없어요"**
  - **공항 노드 없음** — 도시쌍·지역쌍 모두 공항을 엔드포인트로 두지 않음(공항 접근은 후속 트랙)
  - 무방향·대칭이라 상대 페이지에 자동 반영. 풀 매트릭스 아님(의미 있는 코리도어만 큐레이션). **등록 쌍 0개면 유저페이지 이동 섹션 미노출**. 소요시간은 분(정수)만 — 번역 필드 없음
- **카테고리 순서(도시 상세)** — 지역 상세와 동일 구조(대카+중카), 지역과 완전 독립

### 백엔드 요구사항

- **slug 자동 생성** — 영문 지역명(`region_translation` en)에서 slugify(소문자화·공백→하이픈·영숫자와 하이픈 외 제거). 저장 필드로 두되 어드민 편집 노출 없음. 영문명이 비면 slug가 없어 게시 불가(별도 검증 없이 자연 게이트)
- **slug 유니크 가드** — `(city, slug)`는 zone과 테마 카테고리 leaf가 공유하는 네임스페이스(`/region/seoul/gangnam` ↔ `/region/seoul/restaurants`). 충돌 시 저장 차단 + **"'restaurants'는 이 도시에서 이미 카테고리 주소로 쓰고 있어요. 지역 영문명을 다르게 지어 주세요."**
- **활성화 판정** — REGION의 언어별 노출 = 히어로 이미지(canonical) + 해당 언어의 태그·설명 충족 + 부모 CITY 활성화 + 해당 `region_translation.is_publish=true`. 각 언어의 공개 상태는 독립 적용. CITY 노출 = 대표이미지·태그·설명 3종 충족
- **주변 지하철역 저장** — 기존 `region_has_subway` 기반, 신규 스키마 없음. 역·호선명은 `category_translation`으로 이미 다국어(번역 입력 불필요), 부가설명만 언어별 저장
- **이동 편집 저장** — 도시쌍·지역쌍을 `(scope_city, from, to, mode, duration_min)` 단위로 저장. 무방향·대칭(양방향 1행). 도시쌍은 한 쌍에 복수 수단 행
- **카테고리 순서 저장** — `region_category_order(scope_type[city|zone], scope_id, parent_category, category_code, order)`. `parent_category` NULL = 대카 순서 / 대카값 = 그 대카 leaf의 중카 순서. 행 없음 = 기본값 폴백(상속 없음·flat)
- **자동번역** — REGION(지역명·한 줄 소개·설명·태그·persona·역 부가설명) / CITY(설명·태그)를 언어별로 채우는 자동번역 트리거, 새 REGION 번역은 `is_translated_by_ai=true`, `is_publish=false`로 생성
- **지역별 리뷰 공개 토글 제거** — `region_review`는 유저가 지역에 직접 남기는 리뷰가 아니라 스팟 후기가 그 스팟 위치의 법정동으로 복제 적재되는 구조. 2025-03 이후 `region_id`는 전량 null. **어드민 토글만 제거하고 테이블·적재 파이프라인은 유지**(스팟 리뷰 쪽이 깨짐)

### 사람이 수행할 작업

- **REGION 영문명 확정·교정** — slug가 영문명에서 자동 생성되고 생성 후 수정하지 않으므로 Phase 1 정비 시점에 확정. 실측 오타 존재(압구정 영문명이 `Yeouido`로 입력·여의도 영문명 빈칸). 이름 변경 논의 건(한남 → 용산)도 생성 전 결론
- **카드메타 초기 백필** — CITY(대표이미지·태그·설명) / REGION(히어로 이미지·태그·설명). 텍스트는 AI 초안, 히어로 이미지는 실사진 소싱(별도)
- **이동 코리도어 큐레이션** — 의미 있는 도시쌍·지역쌍만 입력(강남↔홍대 등)
- **주변 역·persona 입력** — 지역별 주요 역 연결·부가설명, 추천 대상 카드 작성

### 정책 결정 필요 (TBD)

- **지역명 특수문자 입력 차단** — `압구정/신사` 같은 슬래시가 URL 경로(slug)를 깨뜨리므로 생성 모달에서 입력 검증 + 안내. 차단 문자 범위 확정 필요
- **지역명 생성 후 수정 불가** — 이름 불변 → slug 불변 → URL·SEO 안정(리브랜딩 미고려). 옵션 확정 필요

## 수용 조건

- 지역(REGION) 탭에서 히어로 이미지와 선택 언어의 태그·설명 충족 여부를 공개 가능 상태로 표시하고, 실제 노출은 부모 CITY 활성화와 해당 언어의 `is_publish=true`까지 충족할 때만 허용
- 지역 상세에서 번역이 없는 언어를 추가하고 기존 번역 복사 또는 AI 번역으로 콘텐츠 생성 가능
- 각 `region_translation.is_publish`가 해당 언어의 공개 상태를 독립적으로 제어
- 선택 언어의 공개 상태만 변경되고 다른 언어의 공개 상태는 유지됨
- 지역 공개 토글이 **공개**로 표시되고 별도의 지도 노출 토글이 존재하지 않음
- 부모 CITY 미활성 상태에서 선택 언어의 REGION 공개가 차단됨
- slug가 영문 지역명에서 자동 생성되고 어드민에 편집 필드가 없으며, `(city, slug)` 충돌 시 저장이 차단됨
- 도시(CITY) 탭 이동 편집에서 도시쌍·지역쌍을 한 화면에서 입력하고 공항 노드가 존재하지 않음. 등록 쌍 0개면 유저페이지 이동 섹션이 미노출됨
- 도시 상세·지역 상세 카테고리 순서가 서로 독립적으로 저장되고, 미설정 시 기본값으로 폴백됨
- 지역 범위에서 법정동 미선택 시 구 전체 범위로 동작하고, 시/도 혼합·구 전체 선택이 저장 단계에서 차단됨
