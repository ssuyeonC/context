# P2T2 — /region 어드민 CMS (CITY·REGION 콘텐츠 메타 + 이동 편집 + 카테고리 순서)

**요약** — `/region` 어드민 와이어프레임에 정의된 CITY·REGION 목록과 상세 편집 화면을 구현하고, 화면에서 입력하는 콘텐츠 메타·지역 범위·주요 역·추천 대상·이동 정보·카테고리 순서를 조회·저장·검증한다. **선행: P2-T1 · Phase 1 T2·T3**

## 배경

- 현재 `/region` 어드민에는 스팟 직접 연결·플레이스 연결 등 폐기 대상 필드가 남아 있고, 신규 유저페이지가 사용하는 CITY·REGION 콘텐츠를 관리할 화면이 부족한 상태
- 신규 `/region` 유저페이지는 운영자가 입력한 카드메타·지역 범위·이동 정보·추천 대상을 데이터 소스로 사용하므로 어드민 CMS와 콘텐츠 백필이 선행되어야 함
- CITY 카드메타가 준비되지 않은 REGION 공개와 기존 지도·리뷰 토글이 화면에 함께 남는 혼선 해소 필요

## 구현

### 유저 플로우

- 운영자는 `/region` 어드민에서 **지역(REGION) 탭 / 도시(CITY) 탭**을 전환
- REGION 목록에서 새 지역 페이지를 생성하거나 기존 REGION 상세로 이동하고, 순서 변경·삭제 가능
- REGION 상세 상단의 언어 탭을 전환해 선택 언어의 공개 여부와 콘텐츠 메타를 편집
- REGION 상세에서 범위·주요 역·추천 대상·카테고리 순서를 편집
- CITY 목록에서 편집할 CITY를 선택하고, 상세에서 콘텐츠 메타·도시쌍/지역쌍 이동 정보·카테고리 순서를 편집

### 프론트엔드 요구사항

**와이어프레임 (참고)**

https://wireframes-lkb.pages.dev/#region-domain-admin

**REGION 목록**

- **‘새 지역 페이지 생성’** 버튼 노출
- 목록 컬럼은 순서·ID·지역명·작성자·공개 여부·노출·삭제로 구성
- 순서는 CITY 페이지의 구역 그리드 노출 순서에 활용
- **노출**은 REGION 필수 메타 충족 여부에 따라 표시하며 별도 입력 필드로 제공하지 않음

**REGION 상세 — 언어·기본 정보·메타**

- 상세 상단에 언어 탭을 노출
- 신규 생성 시 **지역명 입력**을 필수로 노출하고, 생성된 REGION의 지역명은 읽기 전용으로 표시
- 부모 CITY 카드메타가 없으면 **“부모 도시 {상위 도시명} 카드메타가 없어 이 지역을 공개할 수 없어요”**와 부족 메타 칩, **“도시(CITY) 메타 편집 →”** 링크 노출
- REGION 메타정보에 히어로 이미지·태그·한 줄 소개·대표 키워드·지역 설명·자동번역 배치
  - **히어로 이미지**는 지역 상세 상단 풀폭 대표 이미지로 사용
  - **태그**는 최대 3개 입력
  - 공개 필수값은 **히어로 이미지·태그·지역 설명** 3종이며, 한 줄 소개와 대표 키워드는 선택 입력
  - **자동번역** 클릭 시 모든 텍스트 입력값을 번역하는 기존 자동번역 모달 노출

**REGION 상세 — 범위**

- 상세지역(구)을 다중 선택하면 구 코드 prefix로 법정동 체크리스트를 자동 도출하고 전체 선택을 기본값으로 적용
- 법정동 수동 추가는 제공하지 않으며 체크 해제로 범위를 축소 가능
  - 한 구의 법정동을 모두 해제하면 저장을 차단하고 **“한 구의 법정동을 모두 해제할 수 없어요 — 구를 빼려면 ‘상세지역 연결 해제’를 사용하세요.”** 노출
- 구 선택 시 상위 CITY를 자동 입력하고 읽기 전용 처리
  - 서로 다른 CITY의 구를 함께 선택하면 저장을 차단하고 **“서로 다른 도시의 구를 함께 담을 수 없어요”** 노출
  - 한 CITY의 상세지역을 전부 선택하면 저장을 차단하고 **“도시 전체 범위의 지역은 만들 수 없어요. 상세지역을 하나 이상 제외해 주세요.”** 노출
- 선택한 구마다 법정동을 하나 이상 선택해야 REGION 생성·저장 가능

**REGION 상세 — 주요 역**

- 호선 선택 후 해당 호선의 지하철역과 부가설명을 직접 입력
- 수도권 지하철 카탈로그로 제공

**REGION 상세 — 추천 대상**

- 라벨·설명·관련 스팟 최대 3개로 구성한 카드 단위 입력
- 카드 추가·삭제·순서 변경 가능
- 입력한 카드가 없으면 유저페이지의 추천 대상 섹션 미노출

**REGION 상세 — 카테고리 순서**

- 대카테고리와 대카별 중카테고리를 중첩 리스트로 재정렬 기능 추가
- REGION 카테고리 순서는 CITY 상세와 독립 저장
- 미설정 시 대카테고리는 `home-nav priority`, 중카테고리는 `category.priority` 순서로 폴백
- 상세 지도 카드 노출 토글과 지역별 리뷰 공개 토글은 노출하지 않음

**CITY 목록**

- 목록 컬럼은 도시명·자식 REGION 수·유저 그리드 노출로 구성
- 자식 REGION이 하나 이상인 CITY만 CITY 탭에 노출
- 자식 REGION이 하나 이상이고 CITY 필수 메타를 모두 입력한 경우에만 **유저 그리드 노출** 상태로 표시

**CITY 상세 — 언어·메타**

- 상세 상단 언어 탭을 전환해 선택 언어의 콘텐츠를 편집
- 도시명은 읽기 전용으로 표시
- CITY 메타정보에 대표 이미지·설명·부가설명·태그·자동번역 배치
- 공개 필수값은 **대표 이미지·설명·태그** 3종이며, 부가설명은 선택 입력
  - 태그는 최대 3개 입력
- **자동번역** 클릭 시 모든 텍스트 입력값을 번역하는 기존 자동번역 모달 노출

**CITY 상세 — 이동 정보**

- 도시쌍과 지역쌍 이동 편집을 한 화면에 제공
  - 도시쌍은 현재 CITY와 다른 CITY 사이에 수단·소요시간을 복수 등록하며, 수단은 비행기·기차(KTX/SRT)·고속버스·택시로 제한
  - 지역쌍은 같은 CITY에 속한 REGION 사이에 수단·소요시간을 복수 등록하며, 수단은 지하철·버스·도보·택시로 제한
  - CITY에 등록된 REGION이 없으면 **“이 도시에 등록된 REGION이 없어 지역쌍을 만들 수 없어요.”** 노출
  - 소요시간은 분 단위 정수로 입력
- 이동쌍은 방향 무관·대칭으로 저장
- 공항은 도시쌍·지역쌍 엔드포인트로 제공하지 않음
- 등록한 이동쌍이 없으면 유저페이지 이동 섹션 미노출

**CITY 상세 — 카테고리 순서**

- REGION 상세와 같은 중첩 리스트 구조로 관리하되 CITY와 REGION의 순서는 서로 독립 저장

### 백엔드 요구사항

- P2-T1의 REGION 생성·번역 구조를 사용해 REGION 목록·상세·수정·삭제·순서 변경과 CITY 목록·상세·수정에 필요한 어드민 API를 제공하고, 신규 REGION 생성 시 이름과 지역 범위를 함께 저장
- 선택 언어의 공개 여부와 화면에서 편집하는 콘텐츠 메타를 저장하고, 필수 메타 충족 여부로 **노출** 상태를 계산해 목록에 반환
- REGION 공개 요청 시 부모 CITY 필수 메타와 선택 언어의 REGION 필수 메타 충족 여부를 검증하고 부족 항목 반환
- REGION 범위 저장 시 선택 구의 동일 CITY 소속 여부, 도시 전체 범위 선택 여부, 선택한 구별 법정동 1개 이상 선택 여부를 검증
- 주요 역·부가설명, 추천 대상 카드, CITY·REGION별 카테고리 순서를 각각 조회·저장
- REGION의 태그·한 줄 소개·설명과 CITY의 태그·설명에 와이어프레임의 **🌐 자동번역** 동작 제공
- 도시쌍·지역쌍마다 이동수단·소요시간을 복수 조회·저장하고, 양쪽 엔드포인트에서 같은 정보가 조회되도록 대칭 저장하며 CITY↔CITY 및 같은 CITY 내 REGION↔REGION 조합과 분 단위 정수 소요시간을 검증

## 수용 조건

- REGION 목록에 새 지역 페이지 생성과 순서·ID·지역명·작성자·공개 여부·노출·삭제가 제공됨
- REGION 상세에서 언어 탭을 전환하고 선택 언어의 공개 여부와 콘텐츠를 편집 가능
- REGION 공개는 부모 CITY 필수 메타와 히어로 이미지·태그·지역 설명을 모두 충족할 때만 가능
- REGION 상세에서 구·법정동 범위를 편집하고, 서로 다른 CITY의 구 혼합·도시 전체 범위 저장을 차단
- 선택한 구마다 법정동이 하나 이상 선택되어야 하며, 한 구의 법정동을 모두 해제하면 REGION 생성·저장을 차단
- 주요 역은 호선별 행으로 직접 등록할 수 있고 연결 역이 없으면 섹션 미노출
- 추천 대상 카드는 라벨·설명·관련 스팟 최대 3개로 구성하며 추가·삭제·순서 변경 가능
- CITY 탭은 자식 REGION이 있는 CITY만 노출하고, 필수 메타 3종을 채운 CITY만 유저 그리드 노출 상태로 표시
- 도시쌍·지역쌍은 CITY 상세 한 화면에서 이동수단·소요시간을 복수 입력하고, 공항 노드는 제공하지 않으며 소요시간은 분 단위 정수로 검증
- CITY·REGION 카테고리 순서는 각각 독립 저장되고 미설정 시 기본 순서로 폴백
- 상세 지도 카드 노출 토글과 지역별 리뷰 공개 토글이 화면에 노출되지 않음
