# T2 — 관광지형 region 구조(구·동) + 데이터 마이그레이션

**요약** — region(관광지형 지명)을 상위 시/군/구에 묶고 그 안에서 법정동(동)을 선택하는 구조를 만들고, 관광지형 지명을 region으로 생성·이관하며 각 region의 동까지 입력한다. 공개는 현행 region 공개 방식을 그대로 사용 — 마이그레이션으로 구·동이 채워지므로 바로 공개 가능

## 배경
- T1에서 상세지역(DETAIL_LOCATION)을 시군구로 정합했으나, 홍대·서면·성수동 등 **행정구역이 아닌 관광지형 지명**은 시군구에 담을 수 없어 region으로 분리 필요
- 블로그 상세지역 사용값 111개 중 **관광지형 83개**(홍대 348·명동 293·경복궁 163 …)가 region 이관 대상
- 현재 region은 상위 구 바인딩·동 선택이 정형화되지 않음 (`legal_location_legal_codes` json nullable)
- 구역 필터가 **시군구 코드 prefix로 스팟을 거르므로**, region이 구+동으로 정확히 묶여야 그 지역 스팟이 걸림
- region 공개는 이미 존재(`region_translation.is_publish`) → 구조·데이터만 갖추면 바로 공개 가능
- → 개편 IA의 구역 필터가 이 구조 위에 서므로 구조·데이터 정비가 선행

## 구현
### 유저 플로우
- 관리자는 region 생성 시 **상세지역(구)을 하나 이상 필수 연결**, 선택한 구들의 공통 상위 도시를 읽기 전용으로 확인
- 구를 연결하면 해당 구의 **법정동(동)을 전체 선택한 상태로 시작**, 일부 체크를 해제해 region 범위 축소 가능
- 선택한 구마다 법정동을 최소 1개 유지해야 하며, 한 구의 법정동을 모두 해제하면 생성·저장 차단
- 관리자는 구·동이 채워진 region을 **현행 공개 방식으로 공개** (마이그레이션분은 동까지 채워져 바로 공개 가능)

### 프론트엔드 요구사항
- region 생성·편집 화면에 **상세지역(구) 연결(필수)** + **법정동 다중 선택(구별 최소 1개)** UI 노출
- 선택한 구 기준으로 하위 법정동 목록을 구 코드 prefix로 자동 도출하고 전체 선택 상태로 노출, 수동 추가는 제공하지 않음
- 일부 법정동 체크 해제로 범위 축소 가능
- 한 구의 법정동을 모두 해제하면 저장 차단하고 **"한 구의 법정동을 모두 해제할 수 없어요 — 구를 빼려면 ‘상세지역 연결 해제’를 사용하세요."** 노출
- 서로 다른 도시의 구 혼합과 한 도시의 상세지역 전부 선택을 저장 단계에서 차단

### 백엔드 요구사항
- region에 **상세지역(구) 하나 이상 연결 필수** — 생성·저장 시 동일 CITY 소속과 도시 전체 범위 금지 검증
- region의 동 선택은 **`legal_location_legal_codes`에 저장(필수)**, 선택한 구마다 법정동이 최소 1개 남도록 검증하며 빈 값을 구 전체 범위로 폴백하지 않음
- **관광지형 지명 region 생성·이관** — 블로그 등에서 쓰인 관광지형 값(83개)을 region으로 생성, 있으면 재사용
- 마이그레이션 시 **각 region의 동까지 채움**
- 본 태스크의 Phase 1 배포에서는 당시 공개 메커니즘 유지, 최종 공개 계약은 P2-T1(COM-2633)의 언어별 `isPublish`와 미번역 폴백 없음 기준 적용
- 스팟 매칭 기준(legal_code prefix)은 현행 유지

### 사람이 수행할 작업
- 관광지형 region ↔ 상위 구 매핑 확정(홍대→마포구 등)
- 각 관광지형 region의 **법정동(동) 매핑 입력** (예: 홍대 → 마포구 서교동·동교동) — 큐레이션
- 현재 공개 중 region이 있으면, 마이그레이션이 라이브 노출을 바꾸는지 검수

## 수용 조건
- 모든 region이 상위 구 바인딩 보유
- 블로그 사용 관광지형 값(83개)이 region으로 생성됨
- 각 region의 선택 구마다 법정동이 1개 이상 입력되고, 구 전체 의도인 경우 해당 구의 법정동 전체 코드가 저장됨
- 마이그레이션 region이 현행 공개 방식으로 정상 노출 가능
