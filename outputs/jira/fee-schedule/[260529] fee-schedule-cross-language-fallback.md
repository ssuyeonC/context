# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

현재 어드민 스팟 상세 페이지의 '기본 선택 입력 정보' 영역에서는 수가표 이미지를 어권별로 따로 업로드해야 한다.

- 운영자는 동일한 수가표 이미지를 노출하기 위해 영어, 일본어, 중국어, 대만어, 홍콩어 페이지에 같은 파일을 반복해서 업로드해야 한다.
- 어권이 다섯 개에 달해 한 스팟당 업로드 횟수가 누적되며, 신규 스팟이나 수가표가 자주 갱신되는 스팟에서는 운영 공수가 크게 발생한다.
- 일부 어권에 업로드가 누락되면 해당 어권 사용자에게 수가표가 노출되지 않아 정보 누락이 발생한다.

### 가설적 임팩트

- 영어 수가표 한 번 업로드만으로 다른 어권에도 자동으로 동일 이미지가 노출되어, 어권별 반복 업로드 작업이 사라진다.
- 어권별 업로드 누락으로 인한 수가표 미노출 케이스가 감소한다.
- 운영자는 어권별로 다른 수가표가 필요한 경우(현지화된 수가표가 있는 경우)에만 추가 업로드를 진행하면 되므로, 업로드 작업이 예외 케이스 중심으로 단순화된다.

## 구현

### 유저 플로우

#### 운영자(어드민) 동작

- 운영자는 어드민 스팟 상세 페이지의 '기본 선택 입력 정보' 영역에서, 기존과 동일하게 어권별로 수가표 이미지를 업로드할 수 있다.
- 운영자가 특정 어권에 이미지를 업로드/삭제하는 동작 자체는 기존과 동일하며, 어권 간 데이터는 독립적으로 저장된다.
- 어드민에서 특정 어권에 직접 업로드된 이미지가 없으면, 해당 어권 영역에는 다른 어권의 이미지를 미리보기로 띄우지 않고 어느 어권의 이미지가 자동 노출되는지를 알리는 안내 문구만 표시한다. 운영자는 이 상태에서 잘못된 이미지를 삭제하거나 변경하지 않도록 보호받는다.

#### 사용자(엔드유저) 노출 동작

- **영어 페이지**를 보는 사용자는 영어 어권에 직접 업로드된 이미지가 있을 때만 수가표를 본다. 다른 어권의 이미지로 대체되어 노출되는 경우는 없다.
- **중국어 페이지**를 보는 사용자는 다음 우선순위로 수가표를 본다.
  1. 중국어 어권에 직접 업로드된 이미지가 있으면, 해당 이미지를 본다.
  2. 중국어에 직접 업로드된 이미지가 없고 대만어 어권에 업로드된 이미지가 있으면, 대만어 이미지를 본다.
  3. 위 두 가지가 모두 없고 영어 어권에 업로드된 이미지가 있으면, 영어 이미지를 본다.
- **대만어 페이지**를 보는 사용자는 다음 우선순위로 수가표를 본다.
  1. 대만어 어권에 직접 업로드된 이미지가 있으면, 해당 이미지를 본다.
  2. 대만어에 직접 업로드된 이미지가 없고 영어 어권에 업로드된 이미지가 있으면, 영어 이미지를 본다.
- **일본어 페이지**를 보는 사용자는 다음 우선순위로 수가표를 본다.
  1. 일본어 어권에 직접 업로드된 이미지가 있으면, 해당 이미지를 본다.
  2. 일본어에 직접 업로드된 이미지가 없고 영어 어권에 업로드된 이미지가 있으면, 영어 이미지를 본다.
- **홍콩어 페이지**를 보는 사용자는 다음 우선순위로 수가표를 본다.
  1. 홍콩어 어권에 직접 업로드된 이미지가 있으면, 해당 이미지를 본다.
  2. 홍콩어에 직접 업로드된 이미지가 없고 영어 어권에 업로드된 이미지가 있으면, 영어 이미지를 본다.
- 어느 어권의 페이지든 우선순위상 적용 가능한 이미지가 하나도 없으면, 수가표 영역은 노출되지 않는다(기존 동작과 동일).

#### 어권 간 업로드 영향 범위 (역방향 정리)

- 운영자가 **영어 어권에 업로드**하면, 자기 어권을 포함해 모든 어권에서 fallback 후보로 동작한다. 단, 일본어/대만어/홍콩어/중국어 페이지에서 더 상위 우선순위 이미지(자기 어권 또는 대만어)가 이미 존재하면 영어 이미지로 대체되지 않는다.
- 운영자가 **대만어 어권에 업로드**하면, 대만어 페이지와 중국어 페이지에서만 fallback 후보로 동작한다. (중국어 페이지 기준 대만어가 영어보다 우선)
- 운영자가 **일본어/홍콩어/중국어 어권에 업로드**하면, 자기 어권 페이지에만 노출된다. 다른 어권 페이지로는 반영되지 않는다.

#### 기존 데이터 처리

- 이 로직 도입 시점에 이미 각 어권에 업로드되어 있는 이미지는 그대로 유지된다.
- 도입 시점에 어권 간 데이터를 일괄 동기화하거나 마이그레이션하지 않는다.

### 프론트엔드 요구사항

#### 어드민 스팟 상세 페이지 - 기본 선택 입력 정보 영역

- 수가표 업로드 입력 UI는 기존과 동일하게 어권별로 분리되어 노출된다. 각 어권 영역에는 제목, 설명, 이미지 영역이 함께 표시된다.
- 운영자는 각 어권 입력 칸에서 이미지를 업로드/삭제할 수 있고, 어권 간 입력은 독립적으로 처리된다.
- 각 어권 영역의 표시 상태는 다음 세 가지로 분기된다.
  - **자기 어권에 직접 업로드된 이미지가 있는 경우**: 기존과 동일하게 업로드된 이미지 썸네일과 함께 '이미지 변경', '삭제' 버튼이 노출된다.
  - **자기 어권에는 업로드된 이미지가 없지만, 우선순위 규칙상 다른 어권 이미지가 사용자에게 자동 노출되는 경우**: 이미지 썸네일은 노출하지 않는다. 대신 어느 어권 이미지가 자동 노출 중인지 안내하는 문구를 표시한다.
    - 예: 일본어 영역 → **"영어 페이지 수가표가 자동 노출됩니다."**
    - 예: 중국어 영역에서 대만어 업로드만 있을 때 → **"대만어 페이지 수가표가 자동 노출됩니다."**
    - 이 상태에서는 '삭제' 버튼을 노출하지 않는다. 이미지 업로드 동작(파일 선택)은 그대로 가능하며, 업로드 시 자기 어권 슬롯에 저장되고 안내 문구는 사라지고 일반 업로드 상태로 전환된다.
  - **자기 어권에도 업로드가 없고, 우선순위 규칙상 다른 어권 이미지도 적용되지 않는 경우**: 기존과 동일한 빈 업로드 상태로 표시된다.
- 영어 어권 영역은 항상 위 분기 중 첫 번째 또는 세 번째 상태만 가질 수 있다(영어는 fallback을 받지 않으므로 자동 노출 안내 문구가 뜨지 않음).

#### 사용자 노출 페이지(스팟 상세)

- 사용자가 보는 스팟 상세 페이지의 수가표 영역에는, 어권별 우선순위 규칙에 따라 결정된 **실제 이미지 한 장이 그대로 노출**된다. 별도의 안내 문구나 라벨은 노출되지 않는다.
  - 예: 영어 페이지에만 수가표가 업로드된 상태에서 일본어 사용자가 페이지를 열면, 일본어 페이지에서 영어 수가표 이미지 자체가 노출된다.
- 우선순위에 따라 적용 가능한 이미지가 하나도 없으면 수가표 영역은 노출되지 않는다.
- 사용자는 자신의 어권 기준으로 대체된 이미지인지 직접 업로드된 이미지인지를 별도로 인지하지 않는다(노출 동작상 차이 없음).

### 백엔드 요구사항

#### 데이터 저장

- 어권별 수가표 이미지는 현재 구조 그대로 어권별 독립 컬럼/필드로 저장한다. 스키마 변경 없이 기존 저장 구조를 유지한다.
- 운영자가 특정 어권에 업로드한 이미지는 해당 어권 슬롯에만 저장되며, 다른 어권 슬롯에 복사 저장하지 않는다(저장 시점이 아닌 조회 시점에 fallback 처리).

#### 조회 로직

- 사용자에게 수가표 이미지를 응답할 때, 사용자 어권을 기준으로 다음 우선순위 규칙을 적용해 단일 이미지 URL을 반환한다.
  - 영어 요청: 영어 슬롯의 이미지만 후보로 사용. 없으면 응답 없음.
  - 중국어 요청: 중국어 → 대만어 → 영어 순으로 먼저 채워진 슬롯의 이미지를 반환.
  - 대만어 요청: 대만어 → 영어 순으로 먼저 채워진 슬롯의 이미지를 반환.
  - 일본어 요청: 일본어 → 영어 순으로 먼저 채워진 슬롯의 이미지를 반환.
  - 홍콩어 요청: 홍콩어 → 영어 순으로 먼저 채워진 슬롯의 이미지를 반환.
- 어드민 응답에서는 어권별 원본 슬롯의 직접 업로드 여부를 반환한다. 어드민 화면에서 "어느 어권 이미지가 자동 노출 중인지" 안내 문구를 결정해야 하므로, 우선순위 규칙에 따른 fallback 적용 결과(어느 어권 슬롯이 노출 대상인지)도 함께 반환한다. 단, fallback 이미지 자체를 어드민 미리보기로 노출하지는 않으므로 응답에서 이미지 URL 중복 전달은 필요하지 않다.

#### 마이그레이션

- 이 기능 배포 시점에 기존 어권별 업로드 데이터에 대한 변환·복사·삭제는 수행하지 않는다.
- 기존에 모든 어권에 동일 이미지가 중복 업로드되어 있는 데이터도 그대로 둔다(자동 정리하지 않음).
