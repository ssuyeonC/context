# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

어드민 집값 알아보기 관리 > 장기숙소 데이터 페이지(`/languagecourse-room-data`)에서 연결할 어학당을 검색하는 세 영역에 일부 어학당이 노출되지 않는 문제 확인

- 대상 영역
  - 상단 **연결 과정명** 검색 필드(다중 선택)
  - **개별 데이터 추가** 모달 내 연결 어학당 검색(단일 선택)
  - **데이터 일괄 추가** 모달 내 연결 어학당 검색(단일 선택)

- 원인 1 — 검색 결과가 첫 페이지 상한까지만 조회, 다음 페이지를 이어 부르는 스크롤·페이지네이션 미구현
  - 연결 과정명 필드는 최대 40건, 두 모달은 최대 100건까지만 조회
  - 검색어를 입력하지 않으면 상한 초과분은 목록에 미노출, 운영자가 원하는 어학당을 이름으로 정확히 타이핑해야만 노출

- 원인 2 — 장기숙소(집값 알아보기) 데이터는 대학교 부설 어학당·단기과정에만 연결되나, 검색 결과에 **어학원** 타입까지 함께 노출되어 잘못된 대상을 연결할 여지

### 가설적 임팩트

- 운영자가 검색만으로 원하는 어학당을 찾지 못하는 불편 해소, 연결 대상 탐색 시간 단축
- 연결 대상 오선택·누락 리스크 감소로 장기숙소 데이터 정합성 개선

## 구현

### 유저 플로우

- 관리자, 세 검색 영역에서 어학당 목록을 스크롤로 끝까지 탐색 가능
- 관리자, 검색어 없이도 대상 어학당 전체를 순차적으로 확인 가능
- 관리자, 검색 결과에 **대학교 어학당**·**단기과정** 타입만 노출, **어학원** 타입은 미노출

### 프론트엔드 요구사항

- 무한스크롤/페이지네이션
  - 세 검색 영역(연결 과정명 필드, 개별 데이터 추가 모달, 데이터 일괄 추가 모달) 드롭다운에 무한스크롤 적용
  - 드롭다운 하단 도달 시 다음 페이지를 이어서 로드하여 기존 목록에 누적, 로딩 중 **로딩 표시** 노출
  - 검색어를 입력한 상태에서도 동일하게 다음 페이지 누적 로드
  - 마지막 페이지 도달 시 추가 요청 중단

- 타입 필터
  - 세 영역 모두 조회 대상을 **대학교 어학당**·**단기과정** 두 타입으로 한정
  - **어학원** 타입은 검색·목록 모두에서 제외

### 백엔드 요구사항

- 어학당 리스트 조회는 이미 타입 필터(대학교·어학원·단기과정 구분)와 page/limit 페이지네이션을 지원 → 위 두 요구사항은 프론트에서 타입 조건 전달과 페이지 증가 요청만으로 해결 가능, 신규 백엔드 변경 불필요
- 현재 어학당 리스트 조회는 한국어 번역이 있는 어학당만 반환(한국어 번역이 없는 어학당은 조회 대상에서 제외). 대상 타입(대학교 어학당·단기과정) 어학당이 모두 한국어 번역을 보유하는지, 예외 존재 여부 확인 필요(TBD)
