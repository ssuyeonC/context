# 세부 기획안 요구사항 문서 — [T4] 트래볼루션 어드민 자동/수동 구분 + 폴백·Slack 알림

> 에픽 `[260819] travolution-api-integration-epic.md` 하위 T4. 선행 T2·T3.

## 배경

### 문제 정의
- 연동 완료 후에도 **매핑된 상품만 API 자동 처리**, 미매핑 상품은 기존 수동 부킹 → 과도기 동안 자동·수동 주문이 한 어드민 화면에 공존
- 연동 실패(호출 오류·타임아웃·거절) 예외 건을 담당자가 확인·개입할 경로와 알림이 필요

### 가설적 임팩트
- **운영 가시성**: 자동/수동 주문 구분으로 어드민 혼선 제거
- **장애 대응**: 실패 건 즉시 인지·폴백으로 주문 누락 방지

## 구현

### 유저 플로우
- (운영자) 어드민 예약내역에서 자동 연동 주문과 수동 주문을 구분해 확인
- (운영자) 연동 실패·거절·타임아웃 건을 Slack 알림으로 인지 → 수동 처리

### 프론트엔드 요구사항
- 어드민 예약내역 테이블에 **API 연동 여부** 컬럼 추가 또는 상위 필터에 **API 연동 여부** 필터 추가(구현 방식 택1)
- 예약 승인대기(PD)·거절(RJ) 건을 어드민에서 상태 확인·개입 가능하게 노출

### 백엔드 요구사항
- **폴백 경로** — 연동 실패(호출 오류·타임아웃·거절) 시 수동 처리 경로 유지, 자동 전환 상품도 예외 건은 담당자 확인·개입
- **알림** — 실패·거절·타임아웃 건 담당자 확인·수동 처리, 알림은 **Slack** 발송(기존 알림 패턴 활용)
- 자동 연동 주문과 기존 수동 주문의 **상태 모델 정합** 유지

**완료조건**
- 어드민에서 자동/수동 주문이 구분 노출·PD/RJ 확인 가능
- 연동 실패 시 Slack 알림 발송 + 수동 폴백 동작
