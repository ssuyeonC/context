# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

메인 홈 상단 배너는 처음 광고 구좌 5개 기준으로 판매를 시작했으나, 광고 캠페인이 늘어나면서 현재 7개의 배너가 세팅되어 있다.

- 유저 페이지의 메인 홈 상단 배너는 **최대 5개까지만 조회·노출**되도록 되어 있어, 등록된 7개 중 나머지 2개는 유저에게 노출되지 않는다.
- 이 때문에 광고주로부터 "배너가 보이지 않는다"는 문의가 접수되고 있다.
- 노출 순서는 고정 배너를 먼저 보여준 뒤 나머지를 랜덤으로 정렬하는 방식이라, 특정 배너가 고정적으로 누락되는 것이 아니라 조회 시점마다 랜덤하게 일부 배너가 노출에서 빠진다.
- 배너 영역 자체는 이미 여러 배너를 자동으로 롤링(순차 노출)하는 구조이므로, 노출 대상 개수만 늘리면 등록된 배너가 모두 롤링되어 보인다. 즉 화면 동작 방식의 추가 개발 없이 노출 개수 상한만 조정하면 되는 사안이다.

이번 요구사항은 메인 홈 **상단(HOME_TOP)** 배너의 최대 노출 개수를 **5개 → 10개**로 확대하는 것을 목표로 한다. (메인 홈 중단·하단 배너는 이번 변경 범위에 포함하지 않으며 기존 5개 기준을 유지한다.)

### 가설적 임팩트

- 현재 등록된 상단 배너 7개가 모두 노출되어, 광고주 노출 누락 문의가 해소된다.
- 광고 세일즈 측면에서 메인 홈 상단 광고 상품을 '최대 10개 구좌' 기준으로 판매할 수 있어, 기존 5개 대비 판매 가능 구좌가 최대 2배까지 확대된다.
- 롤링 노출이므로 구좌가 늘어도 화면 점유 면적은 동일하며, 유저 관점의 UI 변화는 없다.

## 구현

### 유저 플로우

- 유저는 메인 홈 상단 배너 영역에서 등록·게시된 배너를 최대 10개까지 롤링 형태로 순차적으로 본다.
- 유저는 고정 배너가 우선 노출된 뒤, 나머지 배너가 랜덤 순서로 롤링되는 화면을 본다. (기존 정렬 방식 유지)
- 등록된 상단 배너가 10개를 초과하는 경우, 유저는 정렬 순서상 상위 10개까지의 배너만 본다.
- 등록된 상단 배너가 10개 이하인 경우, 유저는 게시 상태인 배너 전체를 본다.

### 프론트엔드 요구사항

- 메인 홈 상단 배너의 조회 개수 상한을 **5 → 10**으로 변경한다.
  - 대상: 유저 페이지 메인 홈의 상단 배너 조회 요청(`bannerExposePosition: HOME_TOP`)의 `limit` 값.
  - 위치(참고): `frontend/apps/web/domain/common/pages/index.tsx` 내 `mainHome` 쿼리의 `homeTopBanners` 항목, `limit: 5` → `limit: 10`.
- 메인 홈 중단(`HOME_MIDDLE`)·하단(`HOME_BOTTOM`) 배너의 `limit` 값은 **변경하지 않고 5로 유지**한다.
- 배너 롤링(캐러셀) 컴포넌트와 정렬 로직은 기존 동작을 그대로 사용하며 추가 변경하지 않는다.

### 백엔드 요구사항

- 별도 변경 없음. 배너 조회 API는 요청받은 `limit` 값을 그대로 적용하며 자체 상한이 없으므로, 프론트엔드에서 전달하는 개수만 조정하면 된다.
