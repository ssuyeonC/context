# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

운영자는 어드민에서 온라인쿠폰별 **유의사항**을 입력하고 있다. 어드민의 해당 입력란에는 "쿠폰 사용시 유저에게 보여지는 유의사항입니다."라는 안내가 붙어 있어, 운영자는 이 내용이 실제 유저에게 노출된다고 인지한 채 작성한다.

그러나 현재 유저 페이지에서는 이 유의사항이 **어디에서도 노출되지 않는다.** 쿠폰 적용 화면(USE COUPON), 내 쿠폰함, 쿠폰 다운로드 카드 어느 곳에서도 유의사항 내용이 화면에 표시되지 않아, 운영자가 입력한 안내가 유저에게 전달되지 않는 누락 상태다.

- 데이터·어드민 입력은 정상적으로 저장된다.
- 유저가 쿠폰을 사용하는 시점에 알아야 할 제약·조건(예: 사용처 한정, 결제 통화 제한, 중복 사용 불가 등)을 확인할 수 없다.

### 가설적 임팩트

- 쿠폰 사용 조건 미인지로 발생하던 사용 실패·문의를 줄여 관련 CS를 절감한다.
- 운영자가 입력한 유의사항이 실제 유저 접점까지 전달되도록 하여, 쿠폰 운영 안내의 신뢰도를 회복한다.
- (정량 지표는 노출 후 쿠폰 관련 CS 인입량 추이로 사후 측정 — TBD)

## 구현

### 유저 플로우

- 유저는 결제 화면에서 쿠폰 적용(**USE COUPON**) 모달을 열어 보유 중인 쿠폰 목록을 본다.
- 유저는 마이페이지의 내 쿠폰함(`mypage/coupon`) 페이지에서 보유 중인 쿠폰 목록을 본다.
- 위 두 화면 모두에서, 유의사항이 등록된 쿠폰에는 카드 안에 접힌 상태의 **유의사항** 토글이 함께 보인다.
- 유저가 토글을 누르면 해당 쿠폰의 유의사항 전문이 펼쳐져 표시되고, 다시 누르면 접힌다.
- 유의사항이 등록되지 않은 쿠폰에는 토글 자체가 보이지 않는다.
- 토글의 펼침/접힘 상태는 쿠폰 카드별로 독립적으로 동작한다.

### 프론트엔드 요구사항

- 다음 두 화면의 **각 쿠폰 카드**에 유의사항 영역을 추가한다.
  - 결제 화면의 쿠폰 적용(**USE COUPON**) 모달.
  - 마이페이지 내 쿠폰함(`mypage/coupon`) 페이지.
- 공통 처리
  - 위치: 쿠폰 카드 내 기존 정보(할인 혜택, 쿠폰명, 사용 기간, 최소 결제 금액, 적용 상태 안내 등) 하단.
  - 유의사항은 내용이 길 수 있으므로 카드에 그대로 펼쳐 넣지 않고 **접힘 기본 상태의 토글**로 둔다.
  - 두 화면의 유의사항 토글은 동일한 노출 규칙·동작을 따른다. (가능하면 공용 컴포넌트로 처리)
- 토글 동작
  - 기본값은 **접힘**.
  - 토글 라벨은 **유의사항**으로 노출한다.
  - 유저가 라벨/토글을 누르면 유의사항 전문이 펼쳐지고, 재클릭 시 접힌다.
  - 펼침 영역에는 운영자가 입력한 유의사항 텍스트를 줄바꿈이 보존된 형태로 노출한다.
- 노출 조건
  - 유의사항 값이 비어 있는(없는) 쿠폰은 토글을 렌더링하지 않는다.
  - 적용 가능/불가, 적용 중 등 쿠폰 카드의 기존 상태 표현과 무관하게 유의사항 토글은 값이 있으면 노출한다.
- 데이터 연동
  - 현재 쿠폰 적용(USE COUPON) 모달과 내 쿠폰함(`mypage/coupon`)의 쿠폰 조회에는 모두 유의사항 값이 포함되어 있지 않다. 두 화면의 쿠폰 조회 시 유의사항 값을 함께 가져오도록 보완한다.
  - (참고) 유의사항 값은 온라인쿠폰 단위로 이미 서버에서 제공 가능한 상태다.
- 제외 대상
  - 쿠폰 다운로드 카드(쿠폰 발급 노출 영역)에는 유의사항 토글을 추가하지 않는다.

### 백엔드 요구사항

- 별도 변경 없음.
  - 유의사항 값은 온라인쿠폰(정률/정액) 데이터에 이미 저장되며, 유저용 조회 응답에 포함 가능한 형태로 제공되고 있다.
  - 어드민의 유의사항 입력·저장 경로도 정상 동작 중이다.
- 단, 쿠폰 적용 화면에서 유의사항 값을 요청했을 때 정상적으로 반환되는지만 확인한다.

### 적용 범위 (참고)

- 적용 대상
  - 결제 화면의 쿠폰 적용(**USE COUPON**) 모달 — 유저가 쿠폰을 사용하는 시점. (어드민 안내 문구 "쿠폰 사용시 유저에게 보여지는 유의사항"과 일치)
  - 마이페이지 내 쿠폰함(`mypage/coupon`) 페이지 — 유저가 보유 쿠폰을 확인하는 시점.
- 제외 대상
  - 쿠폰 다운로드 카드(쿠폰 발급 노출 영역).
