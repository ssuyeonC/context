# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

- 현재 확정(`COMPLETE`) 상태의 예약은 **예약일 +1일** 시점에 자동으로 **사용 완료(`USED`)** 로 전환된다. 그전까지 유저는 해당 예약의 리뷰를 작성할 수 없다.
- 유저 메인 하단의 '오늘의 예약' 플로팅 영역에서 **'리뷰 작성하기' 버튼은 예약이 사용 완료 상태일 때만 노출**된다. 그런데 예약일 당일에는 아직 사용 완료 상태가 아니므로, 정작 방문을 마친 당일에는 버튼이 거의 노출되지 않는다.
- 즉 유저가 시술·체험을 마치고 앱을 여는 시점(예약일 당일)과, 리뷰를 쓸 수 있게 되는 시점(예약일 +1일) 사이에 하루의 공백이 생겨, **리뷰 작성 동선으로의 진입 기회가 크게 손실**된다.
- 처음에는 파트너가 직접 사용 완료 처리하도록 파트너 어드민에 안내를 붙이는 방안을 검토했으나, 기능 사용을 유도하기보다 **정책적으로 예약일(시)이 지나면 자동으로 사용 완료 처리**하는 편이 더 낫다고 판단했다. (파트너 대상 슬랙 논의에서 영업/정산 영향 없음 확인)
- 더불어 플로팅 영역에 '리뷰 작성하기' 버튼이 노출되더라도, 리뷰를 작성했을 때 **얼마의 포인트를 받을 수 있는지 유저가 즉시 알 수 없어** 작성 동기가 약하다.

### 가설적 임팩트

- **'리뷰 작성하기' 버튼 노출 빈도 확대** — 예약일 당일부터 플로팅 영역에 리뷰 버튼이 노출되어, 리뷰 작성 동선 진입률·완료율이 상승한다.
- **리뷰 작성 전환율 상승** — 리뷰 작성으로 받을 수 있는 포인트 총합을 함께 노출해, 플로팅 영역 안에서의 리뷰 작성을 직접 유도한다.
- **CX 문의 감소** — 예약일시 경과 후 일정 유예(+60분)를 두고 전환하므로, 방문이 늦어진 고객이 사용 완료 처리되어 발생하던 문의를 줄인다.

## 구현

### 유저 플로우

**자동 사용 완료 전환**

- 예약일시가 있는 확정 예약은, 예약일시로부터 **60분이 지나면** 자동으로 사용 완료 상태로 전환된다.
- 예약일시가 없는(예약일만 지정된) 확정 예약은, **예약일 당일 23:59**에 자동으로 사용 완료 상태로 전환된다.
- 예약 만료일이 지정된 예약은, 기존과 동일하게 **만료일 +1일** 시점에 사용 완료 상태로 전환되며, 이 정책이 위 두 정책보다 **우선 적용**된다.
- 전환 시점이 앞당겨지더라도, 파트너가 영업 현장에서 직접 사용 완료 처리할 수 있는 기존 버튼은 그대로 유지된다. (현장에서 더 빠르게 사용 완료 처리해 리뷰 작성을 유도해야 하는 경우가 있음)

**유저**

- 방문을 마친 예약일 당일, 예약일시 경과 후 60분이 지나면 해당 예약이 사용 완료 상태가 되어, 유저 메인 플로팅 '오늘의 예약' 영역에 **'리뷰 작성하기' 버튼이 노출**된다.
- 오늘 예약 중 '리뷰 작성하기'가 활성화된 예약이 하나 이상 있으면, 플로팅 영역에 **이 예약들에서 리뷰를 작성해 받을 수 있는 포인트 총합**이 함께 노출된다.
- 유저는 '리뷰 작성하기'를 눌러 기존 리뷰 작성 페이지로 이동하고, 리뷰를 작성하면 포인트를 지급받는다.

### 정책 요약

| 예약 유형 | 기존 전환 시점 | 변경 전환 시점 |
|---|---|---|
| 예약**일시**가 있는 예약 | 예약일 +1일 | **예약일시 +60분** |
| 예약일시가 **없는**(예약일만) 예약 | 예약일 +1일 | **예약일 당일 23:59** |
| **만료일**이 있는 예약 | 만료일 +1일 | 만료일 +1일 (변경 없음 · 위 두 정책에 **우선 적용**) |

### 프론트엔드 요구사항

**리뷰 작성 유도 — 포인트 총합 노출**

- 오늘 예약 중 사용 완료 상태(리뷰 작성 가능)인 예약이 하나 이상 있으면, 플로팅 '오늘의 예약' 영역에 해당 예약들에서 리뷰 작성 시 받을 수 있는 **포인트 총합**을 노출한다.
- 총합은 **리뷰 작성 가능한 각 예약의 (기본 리뷰 포인트 + 사진 첨부 등 추가 조건 포인트)를 모두 합산**한 값이다.
  - 예) 오늘 예약 5건 중 3건이 사용 완료 상태로 리뷰 작성이 활성화되어 있다면, 그 3건에 대해 기본 + 사진 추가 조건까지 충족해 리뷰를 작성했을 때 받을 수 있는 포인트의 합.
- 사진 첨부 등 추가 조건까지 충족했을 때의 최대 지급 포인트를 기준으로 하므로 '최대'로 표기한다.
  - 안내 카피(예시): **"지금 리뷰 쓰고 최대 {N}P 받아가세요"** — 최종 문구 TBD
- 리뷰 작성이 활성화된 예약이 없으면 포인트 총합 영역은 노출하지 않는다.

**노출 조건**

- 기존 플로팅 '오늘의 예약' 영역의 노출 정책을 그대로 따른다. (모바일 메인 한정, 로그인 유저, 오늘 KST 예약) — [260528] 유저 메인 '오늘의 예약' 플로팅 섹션 문서 참조
- 리뷰 작성 가능 판단은 기존과 동일하게 사용 완료 상태 + 미작성 예약에 한한다.
- 자동 전환 시점 변경으로 예약일 당일에도 사용 완료 예약이 노출될 수 있으므로, 카드의 방문 전/방문 후 모드 전환이 당일 내에 자연스럽게 이뤄져야 한다.

### 백엔드 요구사항

**자동 사용 완료 전환 로직 변경**

- 확정 예약을 사용 완료로 전환하는 기존 자동 처리 기준을 아래로 변경한다.
  - 예약일시가 있는 예약: **예약일시 + 60분**이 지난 시점에 사용 완료로 전환한다.
  - 예약일시가 없는 예약: **예약일 당일 23:59**(KST)에 사용 완료로 전환한다.
  - 만료일이 있는 예약: **만료일 +1일**에 사용 완료로 전환하며, 위 두 기준보다 우선 적용한다. (기존 로직 유지)
- 시간 기준은 한국 KST로 통일한다.
- 파트너가 직접 사용 완료 처리하는 기존 기능·상태 전이는 변경 없이 유지한다.

**포인트 총합 산출**

- 오늘 예약 목록 조회 응답에, 리뷰 작성 가능한 각 예약에 대해 **리뷰 작성 시 획득 가능한 포인트(기본 + 사진 등 추가 조건 최대치)** 정보를 포함한다.
- 상품/리뷰 정책별로 지급 포인트가 다를 수 있으므로, 예약(상품) 단위의 획득 가능 포인트를 기준으로 산출한다.
- 총합 표시를 위한 합산은 응답에 포함된 예약별 획득 가능 포인트를 기준으로 하며, 합산 위치(백엔드 집계 vs 프론트 합산)는 구현 협의 시 결정한다. (TBD)
