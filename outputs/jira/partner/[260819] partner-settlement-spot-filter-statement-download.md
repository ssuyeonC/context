# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

- 하나의 파트너 계정에 여러 업체(지점)가 연결된 경우, 파트너십 정산 페이지에서 모든 업체의 정산 내역이 **합산되어 노출** — 특정 지점의 정산 내역만 별도로 확인하기 어려움
- 여러 지점을 운영하는 파트너사의 경우 **업체별 정산 내역 확인 및 정산서 요청이 반복 발생**
- 현재 정산 페이지의 필터는 판매일·언어뿐이며, **업체(지점) 선택 필터가 없음**
- 월별 정산서는 발행되어 파트너에게 메일로 전달되나, 파트너가 페이지에서 **직접 조회·다운로드하는 수단이 없음** → 반복 요청과 담당자의 수동 전달 업무 발생
- 언어 필터는 특정 언어를 선택한 뒤 전체 어권으로 되돌리는 수단이 미흡 — 초기화(새로고침) 버튼만 있고 **'전체 언어' 선택지가 명시되어 있지 않음**

### 가설적 임팩트

- 업체별 구분 조회와 정산서 셀프 다운로드 제공으로 **파트너 반복 문의 및 담당자 수동 전달 업무 감소** 기대
- 파트너의 정산 내역 자가 확인성 향상으로 정산 관련 운영 커뮤니케이션 비용 절감 기대

## 구현

### 유저 플로우

- **업체별 정산 조회**
    - 파트너가 정산 페이지 진입 시 기본값 **전체 업체** — 연결된 모든 업체의 정산 내역을 합산하여 노출 (현재와 동일)
    - 특정 업체 선택 시 **선택한 업체의 정산 금액·정산 내역만 노출**
- **월별 정산서 다운로드**
    - 파트너가 **정산 월 선택 → 정산서 다운로드**
    - 파트너 본인에게 발행된 정산서만 접근 가능
    - **파트너 단위 월별 정산서**를 그대로 다운로드 — 업체(스팟) 단위 분리 다운로드는 하지 않음 (확정)
    - **다운로드 문서 = 메일 발송 문서와 완전 동일** (발송된 실제 파일을 보관·제공, 재산출 아님) — 유관부서 확정
    - **적용 범위: 기능 구현일 이후 발행분부터** 다운로드 가능. **구현일 이전 과거 정산서는 다운로드 불가** (기존 저장분은 파트너·월로 되찾을 수 없어 백필 불가 — 아래 백엔드 참조)
- **언어 필터**
    - 특정 언어를 선택한 뒤 **전체 언어**로 되돌려 전체 어권 정산 내역을 다시 노출

### 프론트엔드 요구사항

- 정산 페이지에 **업체(지점) 선택 필터** 추가, 기본값 **전체 업체**
- 예약내역 화면에서 이미 제공 중인 업체 선택 방식과 동일한 사용 흐름으로 배치
- 선택한 업체에 따라 정산 금액·정산 내역, 그리고 정산서 다운로드 대상이 함께 필터링되도록 연동
- 언어 필터에 **전체 언어** 선택지(또는 전체 어권 복귀 버튼)를 명시적으로 노출 — 특정 언어 선택 후에도 전체로 되돌아갈 수 있도록
- 월별 정산서 다운로드 영역 추가 — 정산 월 선택 후 다운로드, **파트너 본인 발행분만** 노출
- 정산서는 **파트너 단위 월별** 파일 하나로 제공 — 업체(스팟) 단위 분리 다운로드 UI 없음

### 백엔드 요구사항

- **업체별 정산 조회**
    - 정산 조회 API에 업체(스팟) 기준 필터 파라미터가 이미 존재 — 프론트 연동으로 대응, 신규 개발 최소
- **월별 정산서 다운로드**
    - 현재 정산서는 매월 1일 발행 배치(정산서 발행 시스템)가 전월 결제내역을 기준으로 파트너별 PDF·엑셀을 생성하여 파트너에게 메일로 발송. 발송된 개별 파일은 파트너·정산월 기준으로 되찾을 수 있게 보관되지 않고(무작위 이름으로 임시 저장 후 폐기), 전체 파트너를 하나로 묶은 압축본만 내부 공유 채널에 남아 **특정 파트너의 특정 월 정산서를 지목해 다시 내려받을 수단이 없음**
    - **다운로드 문서 = 메일 발송 문서 완전 동일** (유관부서 확정) — 파트너가 받는 파일은 **재산출본이 아니라 발송 당시 그 파일 그대로**. 발행 이후 환불·정정이 생겨도 다운로드 문서는 **발송 시점 값 그대로** 유지하여 실제 정산 입금액과 일치
    - **적용 범위: 기능 구현일 이후 발행분부터** 다운로드 제공. **구현일 이전 과거 정산서는 제외** — 기존 발송분은 파트너·월 기준으로 보관되어 있지 않아 소급 복원이 어려움

    - **정산서 발행 시스템(발행 배치) 측 수정**
        - 파트너별 정산서 파일을 발행 시 폐기하지 않고, **파트너·정산월 단위로 되찾을 수 있는 위치·이름으로 영속 저장** — 현재 무작위 이름·일회성 저장 구조를 조회 가능한 형태로 변경
        - 저장 파일 접근을 **비공개로 전환** — 현재 엑셀 정산서가 인증 없이 열리는 공개 상태이므로, 링크만 알면 누구나 열람 가능한 노출을 차단
        - 발행 시점에 **발행 이력 기록** — 파트너·정산월·정산서 종류(예약/부가상품)별로 해당 파일 위치를 남겨, 이후 조회 시 파일을 특정할 수 있도록 함
        - 정산서에 반영되는 대상·산출 로직은 기존 발행 로직과 동일 유지 (결제 완료·부분 환불 상태 예약 기준, 결제구분별 정산서 종류(수수료공제/정산가정산) 및 부가상품 정산서 구분 그대로)

    - **파트너 페이지(서비스) 측 수정**
        - 파트너가 정산 월을 선택하면 **발행 이력을 조회**하여 해당 파트너·월의 정산서 파일을 특정
        - **파트너 본인 발행분만** 접근하도록 권한 처리 — 다른 파트너의 정산서에 접근 불가
        - 다운로드는 **만료형(임시) 다운로드 링크** 등 본인만 받을 수 있는 접근 방식으로 제공
