# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

- 하나의 파트너 계정에 여러 업체(지점)가 연결된 경우, 파트너십 정산 페이지에서 모든 업체의 정산 내역이 **합산되어 노출** — 특정 지점의 정산 내역만 별도로 확인하기 어려움
- 여러 지점을 운영하는 파트너사의 경우 **업체별 정산 내역 확인 및 정산서 요청이 반복 발생**
- 현재 정산 페이지의 필터는 판매일·언어뿐이며, **업체(지점) 선택 필터가 없음**
- 월별 정산서는 발행되어 파트너에게 메일로 전달되나, 파트너가 페이지에서 **직접 조회·다운로드하는 수단이 없음** → 반복 요청과 담당자의 수동 전달 업무 발생
- 언어 필터는 특정 언어를 선택한 뒤 전체 어권으로 되돌리는 수단이 미흡 — 초기화(새로고침) 버튼만 있고 **'전체 언어' 선택지가 명시되어 있지 않음**

- 업체별 구분 조회와 정산서 셀프 다운로드 제공으로 **파트너 반복 문의 및 담당자 수동 전달 업무 감소** 기대
- 파트너의 정산 내역 자가 확인성 향상으로 정산 관련 운영 커뮤니케이션 비용 절감 기대

## 구현

### 유저 플로우

- **업체별 정산 조회**
    - 파트너가 정산 페이지 진입 시 기본값 **전체 업체** — 연결된 모든 업체의 정산 내역을 합산하여 노출 (현재와 동일)
    - 특정 업체 선택 시 **선택한 업체의 정산 금액·정산 내역만 노출**
- **월별 정산서 다운로드**
    - 파트너가 **정산 월 선택 → 정산서 다운로드**
    - 파트너 본인에게 발행된 정산서만 접근 가능
    - 업체(스팟) 단위로 구분하여 다운로드하는 방식의 필요 여부는 운영팀 확인 중 — TBD
- **언어 필터**
    - 특정 언어를 선택한 뒤 **전체 언어**로 되돌려 전체 어권 정산 내역을 다시 노출

### 프론트엔드 요구사항

- 정산 페이지에 **업체(지점) 선택 필터** 추가, 기본값 **전체 업체**
- 예약내역 화면에서 이미 제공 중인 업체 선택 방식과 동일한 사용 흐름으로 배치
- 선택한 업체에 따라 정산 금액·정산 내역, 그리고 정산서 다운로드 대상이 함께 필터링되도록 연동
- 언어 필터에 **전체 언어** 선택지(또는 전체 어권 복귀 버튼)를 명시적으로 노출 — 특정 언어 선택 후에도 전체로 되돌아갈 수 있도록
- 월별 정산서 다운로드 영역 추가 — 정산 월 선택 후 다운로드, **파트너 본인 발행분만** 노출
- 업체(스팟) 단위 정산서 다운로드 UI는 운영팀 확인 결과에 따라 확정 — TBD

### 백엔드 요구사항

- **업체별 정산 조회**
    - 정산 조회 API에 업체(스팟) 기준 필터 파라미터가 이미 존재 — 프론트 연동으로 대응, 신규 개발 최소
- **월별 정산서 다운로드**
    - 현재 정산서는 외부 정산서 발행 처리(발행 배치)에서 **파트너 단위**로 생성되어 S3에 보관되나, 배치 결과가 여러 파트너를 묶은 단일 압축본(무작위 경로)으로만 남아 **파트너·정산월 단위로 특정 정산서를 되찾을 기록(포인터)이 없음**
    - 파트너 셀프 다운로드를 위해, 발행 시점에 **파트너·정산월(→ 필요 시 업체) → 개별 정산서 파일 위치**를 조회 가능한 형태로 저장하는 정산서 발행 이력 관리 신설 필요
    - 개별 파트너 파일을 되찾으려면 발행 처리(배치) 측에서 **파트너별 파일을 개별 저장하고 그 위치를 반환**하도록 연계 필요 — 발행 처리 담당과 협의 필요
    - 저장된 정산서는 **파트너 본인만 조회·다운로드**하도록 인증·권한 처리 — 현재 인증 없이 접근되는 공개 경로 형태이므로 접근 제어 필요
    - 정산서 생성 단위를 업체(스팟)별로 분리 가능한지 여부는 발행 처리(배치) 확인 필요 — TBD
    - 정산서에 반영되는 대상은 기존 발행 로직과 동일 유지 (결제 완료·부분 환불 상태 예약 기준)
