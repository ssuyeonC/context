# 세부 기획안 요구사항 문서

## 배경

### 문제 정의

피부시술 카테고리 스팟을 운영하는 파트너에게는 별도의 **전용 정산 페이지**가 제공되지만, 파트너 어드민의 **'파트너십 정산'** 탭에서 이 전용 정산 페이지로 이동할 진입점이 없다.

- 대상 파트너는 전용 정산 정보를 확인하려면 별도 경로를 안내받아야 하며, 파트너 어드민 안에서 자연스럽게 이어지지 않는다. (전용 정산 페이지의 성격·주소: TBD)
- 진입 동선이 끊겨 있어 관련 안내·문의 부하가 발생한다.

### 가설적 임팩트

- '파트너십 정산' 탭에 전용 정산 페이지로 이동하는 배너를 노출하면, 대상 파트너의 전용 정산 페이지 진입률이 올라간다.
- 전용 정산 페이지 안내를 위한 개별 소통 부하가 줄어든다.
- (정량 임팩트: 대상 파트너의 전용 정산 페이지 진입률·정산 관련 문의 건수 기준으로 산정 필요 — TBD)

## 구현

### 유저 플로우

- 파트너가 좌측 네비게이션의 **'파트너십 정산'** 탭에 진입한다.
- 파트너가 보유한 스팟의 연결 카테고리에 **404(중분류 '피부시술(사용중)')** 가 포함된 경우, 정산 화면 상단에 **전용 정산 페이지로 이동하는 배너**가 노출된다.
- 위 조건에 해당하지 않는 파트너에게는 배너가 노출되지 않는다.
- 파트너가 배너를 클릭하면 전용 정산 페이지로 이동한다. (이동 대상 주소: TBD)

### 프론트엔드 요구사항

- '파트너십 정산' 탭 진입 화면 **상단에 배너 영역**을 배치한다.
- 배너 노출 여부는 아래 노출 조건에 따라 분기한다.
- 배너 카피·디자인은 확정 필요. (노출 문구: TBD)
- 배너 클릭 시 전용 정산 페이지로 이동시킨다. (이동 방식·주소: TBD)

### 백엔드 요구사항

- 배너 노출 조건을 판별하기 위해, 파트너가 보유한 스팟의 **연결 카테고리에 404(중분류 '피부시술(사용중)')가 포함되는지** 조회한다. (파트너 등급·유형이 아니라 보유 스팟의 카테고리 기준)
- 전용 정산 페이지 연동 방식·주소를 확정하여 제공한다. (TBD)
