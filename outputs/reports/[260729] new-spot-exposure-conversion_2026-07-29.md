# 신규 상품(New 뱃지) 유입·전환 분석 — 노출 병목 진단

작성일: 2026-07-29
분석자: 수연 (with Claude)
데이터 출처: BigQuery `dashboard_ga4.SpotDetailPV` · `dashboard_db.spot_sales` · `db_view.spot_information` / 코드 `frontend/apps/web/domain/travel/subdomain/spot/SpotDomainService.ts`, `SpotOrderFilter.tsx`

---

## 0. 배경 · 질문

- **문제의식**: 입점 상품 중 '새 상품'의 전환율이 다른 스팟 대비 낮다는 인식이 있음. 통상 리뷰 수·퀄리티가 전환율과 정의 상관 → "신규 상품에 리뷰를 붙여야 한다"는 명제가 나오는 중.
- **경쟁 가설**: 신규 상품은 플랫폼 내 **디폴트 노출 지면이 사실상 없다**(리스트에서 유저가 직접 필터/정렬해야 우선 노출). 즉 전환력 자체보다 **노출 기회 부족**이 기여할 수 있음.
- **검증 질문**: ① New 딱지 스팟 vs 기타 스팟 전환율, ② 절대 유입량, ③ 스팟 리스트에서 '새 상품' 정렬로 변경한 수.

## 1. 핵심 요약 (TL;DR)

- **전환율 격차는 생각보다 크지 않다.** 조회당 전환율 New **1.23%** vs 기타 **1.47%** → New가 **약 −16%** 수준(파괴적이지 않음).
- **진짜 병목은 노출량이다.** 신규 상품 전체 트래픽은 **전체 스팟 조회의 6.6%**에 불과. 스팟당 평균 노출은 기타의 **약 58%**, 판매가능 신규 상품의 **23.6%는 한 달간 상세 조회 0회**, 노출 중앙값 **월 44회**(기타 평균 327회).
- **결정적**: 스팟 리스트 페이지에 **'새 상품(등록순)' 정렬 옵션이 아예 없다.** "New" 뱃지는 카드에 표시만 될 뿐 **랭킹/노출에 전혀 영향 없음.** 즉 "필터를 클릭해야 보인다"는 전제보다 상황이 더 나쁘다 — **클릭할 필터 자체가 없다.**
- **결론**: 리뷰 추가(전환율 개선)와 **별개로**, **노출 지면 확보**가 더 큰 레버일 가능성이 높다.

## 2. 방법 · 정의

- **분석 기간**: 최근 30일 완결 구간 **2026-06-29 ~ 2026-07-28**.
- **신규 판정**: 코드의 실제 뱃지 로직을 **이벤트 단위로 그대로 적용**.
  - `SpotDomainService.isNew`: `createdAt`이 조회 시점 기준 **90일 이내**면 New (`NEW_SPOT_EXPIRY_DAYS = 90`, KST).
  - 조회 이벤트는 `event_date`, 결제는 `pay_paid_date` 각각을 기준으로 그 시점 뱃지 여부 판정 → 조회/전환 분류가 일관.
- **유입(분모)**: `SpotDetailPV`, 판매 가능 상품(`type_name='GENERAL'`)만.
- **전환(분자)**: `spot_sales`의 distinct `reserve_code`(결제 완료 주문 수).
- **전환율**: 집계 레벨 비율(주문/조회). 세션 코호트 추적이 아니라 상품군 레벨 프록시임(아래 한계 참고).

## 3. 전환율 — New vs 기타 (2026-06-29~07-28, GENERAL)

| 지표 | New (뱃지) | 기타(established) | 격차 |
|---|---|---|---|
| 상세페이지 조회수(PV) | 40,006 | 563,715 | New = 전체의 **6.6%** |
| 조회 유저수 | 19,600 | 190,705 | |
| 주문수(distinct reserve) | 492 | 8,288 | |
| **전환율(주문/PV)** | **1.23%** | **1.47%** | **New −16%** |
| 전환율(주문/조회유저) | 2.51% | 4.35% | New −42% |
| 스팟당 평균 PV | 190.5 | 327.2 | New = 기타의 **58%** |

- **조회당 전환율(1.23% vs 1.47%)**이 가장 깨끗한 비교 — New가 낮긴 하나 **−16% 수준**.
- 유저당 전환율 격차(−42%)가 커 보이는 건 기타 스팟 방문자가 유저당 더 많이 탐색하기 때문(PV/유저 2.96 vs 2.04)이라, 순수 전환력 격차로 보긴 어렵다.

## 4. 노출 — 절대 유입량 (핵심)

- 신규 상품 전체 트래픽 = **전체 스팟 조회의 6.6%**. (조회된 스팟의 10.9%가 신규인데 조회 점유율은 그보다 낮음 → 상대적 과소노출)
- **판매가능 신규 상품 229개**의 30일 유입 분포(0 조회 포함):

| 구간 | 스팟 수 | 비중 |
|---|---|---|
| 상세 조회 0회 | 54 | **23.6%** |
| 1–49 PV | 69 | 30.1% |
| 50–199 PV | 75 | 32.8% |
| 200+ PV | 31 | 13.5% |
| **평균 126.7 PV · 중앙값 44 PV** | | (기타 평균 327의 절반 이하) |

→ **절반 이상의 신규 상품이 월 44회 이하로만 노출.** "디폴트 노출 지면이 없다"는 진단이 수치로 확인됨.

## 5. '새 상품' 정렬 변경 수 → 측정 불가 (정렬 자체가 없음)

코드 확인 결과(`SpotOrderFilter.tsx`):

- 스팟 리스트 정렬 옵션은 **최고평점 / 최신 업데이트(RenewalDate=정보 *수정*일) / 가격↓ / 가격↑ / 월간인기 / 만족도순** 6개뿐.
- **'새 상품/등록순(CREATED_AT)' 정렬은 없음.** 백엔드 `SpotOrderType` enum엔 `CREATED_AT`이 정의돼 있으나 **프론트 미노출**. (CREATED_AT은 리뷰·포토리뷰 정렬에만 사용)
- "New" 뱃지는 카드 표시용일 뿐 **랭킹/노출 로직과 무관.**
- 정렬 관련 GA 이벤트는 `ListOrderFilterClick`(필터 *열림*만 기록, 선택값 파라미터 없음) → 특정 정렬 선택 횟수는 **GA/BigQuery에도 잡히지 않음.**

→ 원 질문의 "정렬을 새 상품으로 바꾼 수"는 **측정 불가이자, 애초에 그런 조작이 불가능**하다.

## 6. 해석 · 제언

- **가설 재정렬**: "신규 전환율이 낮다"보다 **"신규 노출이 구조적으로 없다"**가 더 정확한 병목. 리뷰 추가(전환율 개선)와 별개로 **노출 지면 확보**가 더 큰 레버.
- **빠른 실험 후보**
  1. 리스트에 **'새 상품(등록순)' 정렬 추가** — 백엔드 enum(`CREATED_AT`) 이미 존재, 프론트 노출만.
  2. 홈/카테고리에 **신상품 노출 지면**(전용 섹션/캐러셀).
  3. 기존 상품 상세에 **"비슷한 신상품" 슬롯**.
- **후속 분석**: 전환율 비교에는 **카테고리 교란**이 있음 — 신규군에 신사업/메디컬(건강검진·시력교정 등 고관여·저CVR·고단가) 비중이 큼. 정확한 전환력 비교는 **동일 카테고리 내 신규 vs 기존** 매칭 분석 권장.

## 7. 한계

- 전환율은 집계 레벨 비율(주문/조회) 프록시 — 조회 유저와 결제 유저가 동일 코호트로 매칭되지 않음(지연·타세션 전환 미분리).
- 신규 판정은 이벤트 시점 뱃지 로직 재현이나, 기간 중 신규→기타로 넘어가는 스팟이 존재(경계값 근사).
- 유입은 `SpotDetailPV`(상세 진입) 기준 — 리스트 노출(impression)·클릭률 자체는 별도 데이터 필요.
