## 0. 배경

- **서비스**: 유저가 본인의 한국 여행 계획을 공유하면 타당성을 분석해 **PDF**로 회신. 비회원도 이용 가능.
- **트래킹**: PDF 내 추천 스팟 하이퍼링크에 `utm_source=creatrip&utm_medium=itinerary_check&utm_content={id}` 부착.
- **질문**: PDF → 스팟 상세 진입이 얼마나 되나? 진입 유저의 주요 액션(결제·교차탐색·일정생성·좋아요·가입) 전환은?

## 1. 핵심 요약 (TL;DR)

- **측정 방식에 따라 결과가 극단적으로 갈린다.** UTM(GA 세션 last-click)은 "진입 그 세션 안에서 즉시 한 행동"만 잡고, 이메일 매칭은 "공유 이후 모든 채널·세션의 지연 전환"까지 잡는다.
- **UTM 기준**: 진입은 잡히나 절대량이 작고(누적 34 PV·진입 유저 ~10명), 세션 내 하단 전환(결제·가입)은 사실상 0. **단, 이건 "한 세션 안에서 바로"의 값이라 서비스의 실제 기여를 크게 과소평가함.**
- **이메일 기준(실사용자 66명)**: **결제 20%·신규가입 24%(비회원의 46%)·좋아요 18%** 로, 서비스가 실제 비즈니스 성과에 기여하고 있음이 드러남.
- **결론**: 이 서비스 성과는 **UTM 단독으로 판단하면 안 되고**, 이메일→회원/예약 매칭 기반의 지연 전환을 병행해야 한다.

## 3. UTM 기준 분석 — "한 세션 안에서 바로 한 행동"

> `last_click_session_source='creatrip' AND medium='itinerary_check'` 로 귀속된 세션. **PDF 클릭 → 그 세션 내 즉시 행동만 반영**(지연·재방문 전환 미포함).

**진입(스팟 상세 PV)**
- 누적 34 PV / 진입 유저 ~10명 / 20개 스팟 (2026-05-04 ~ 07-21)
- 월별: 5월 13 · 6월 11 · 7월 10 PV
- 전체 스팟상세 PV 대비 **0.0016~0.0022%** (절대량은 미미)
- CTR 추정: 진입 ~10-11명 / 개선 이후 수신자 ~49명 ≈ **약 22%** (분모 정밀화 여지 있음)

**세션 내 액션 (진입 유저 ~10 기준)**
| 액션 | 전환 | 비율 |
|---|---|---|
| 교차 탐색 (세션 내 ≥2개 스팟 조회) | 4명 | **40%** (2명은 6·7개까지 탐색) |
| 스팟 결제 | 0 완료 (1명 예약옵션 선택까지) | 0% |
| 여행 일정 생성 | 0 | 0% |
| 좋아요 | 0 | 0% |
| 회원가입 | 0 | 0% |

**해석**: PDF 링크는 **세션 내 탐색 유도(교차탐색 40%)에는 효과적**. 다만 결제·가입 등은 한 세션 안에서 바로 일어나지 않음 → **아래 이메일 기준으로 지연 전환을 봐야 함.**

## 5. 두 관점 비교 (같은 서비스, 다른 렌즈)

| | UTM (세션 last-click) | 이메일 (공유 후 전면) |
|---|---|---|
| 측정 대상 | 진입 세션 내 **즉시** 행동 | 모든 채널·세션의 **지연** 전환 포함 |
| 진입 | ~10명 | (진입은 UTM으로만 측정) |
| 결제 | 0 | **13명 (20%)** |
| 신규가입 | 0 | **16명 (24%)** |
| 강점 | PDF 클릭률·즉시 탐색 측정 | 실제 비즈니스 기여 측정 |
| 한계 | 지연·재방문 전환 누락(과소집계) | 인과 불확실(상관), 관찰창 불균등 |

**왜 다른가**: 유저가 PDF로 스팟을 본 뒤 **며칠 후 다이렉트/검색으로 재방문해 결제**한다. GA last-click은 이 결제를 다른 소스로 귀속시켜 `itinerary_check` 성과에서 누락시킨다. 이메일 매칭은 그 지연 전환을 회수한다.

## 6. 반드시 감안할 한계

1. **UTM = 세션 내 즉시 행동만.** UTM의 "0 결제/0 가입"은 실패가 아니라 **측정 범위의 한계**(한 세션 안에서 바로 안 일어났을 뿐). 실제 기여는 이메일 기준 참조.
2. **이메일 기준 = 상관, 인과 아님.** "공유 후 액션"이 서비스 때문이라는 보장 없음. 특히 기존 회원 8명 결제는 원래 구매층일 수 있음. (신규 가입자 전환이 더 깨끗한 증거)
3. **관찰창 불균등.** 4월 유저는 3개월, 7월 유저는 며칠뿐 → **최근 코호트 전환은 아직 덜 여물어 과소집계**(오늘 공유한 유저는 당연히 0).
4. **이메일 불일치.** 비회원 19명 중 일부는 다른 이메일로 가입한 회원일 수 있어 실제 전환은 더 높을 여지.
5. **N이 작음(66).** 1명 = 약 1.5%p. 방향성 참고용.

## 7. 제언

- **성과 측정을 UTM에만 의존하지 말 것.** PDF 발송·요청 로그(이메일)와 회원/예약 DB를 조인한 지연 전환을 정기 지표로 둔다.
- **분모 정밀화**: 병준님께 외부 스크립트의 UTM 링크 실제 배포일 확인 → 4월 블라인드 경계 확정(현재 05-04 기준, CTR ~22%).
- **최근 코호트 재측정**: 7월 요청 37건은 아직 전환 진행 중 → 4~6주 후 재집계 시 전환율 상승 예상.
- **확산 검토**: 비회원 46% 가입·결제 20%는 신규 획득 채널로서 유의미. 요청량(7월 급증) 대비 확산 여력 검토.
